# Semantic Anchoring for Robotic Action Representations

- arXiv: 2607.13597
- 主题：VLA、Action Representation、Semantic Alignment、OOD Generalization

## 1. 核心问题

这篇论文关注的不是新的 VLA backbone，而是一个更基础的问题：**机器人策略内部的 action representation 应该具有什么结构，才能更好地泛化？**

作者观察到，预训练 VLM/VLA 中原本存在较清晰的任务级语义结构，但在 robot action-only finetuning 后，这种结构会逐渐退化。模型在训练分布内的 success rate 仍然可以继续上升，但 action representation 与 task semantics 的对齐程度、以及 OOD performance，却会同步下降。

因此作者提出一个核心假设：

> 对 OOD generalization 有帮助的 action representation，不应该只是“能解码出正确动作”，还应该保留任务级 intention / semantics。

论文试图将 action representation 组织成：

```text
Action representation
        ↓
  ┌───────────────┐
  │ Shared        │ → task intention / semantics
  │ Private       │ → embodiment / geometry / timing / motor details
  └───────────────┘
```

其中只把 Shared 部分与冻结的外部 semantic encoder 对齐，Private 部分保留低层控制需要的细节。

---

## 2. 论文首先做的 diagnostic：Action–Instruction Alignment

作者先不改策略，而是问：**当前 VLA 的 action-token hidden representation，到底还保留了多少 instruction semantics？**

以 π0 为例，从某个中间层（默认分析中使用第 10 层）取 action-token hidden states：

\[
h_1^{(k)},\ldots,h_T^{(k)}.
\]

对 action tokens 做 pooling，得到 action-level feature：

\[
\bar h_a^{(k)}.
\]

另一方面，将 instruction 输入一个冻结的外部 text / vision-language embedding encoder，得到：

\[
e_t=g_{\text{sem}}(l).
\]

然后分别经过两个可训练 projection head：

\[
z_a=T_a(\bar h_a),
\]

\[
z_t=T_t(e_t).
\]

两边投到同一个维度后，用 cosine similarity + 双向 InfoNCE 做 action ↔ instruction retrieval。

### 关键观察

随着 robot finetuning 进行：

- ID success 持续提高；
- action–instruction alignment 会明显下降；
- OOD success 与 alignment 的变化高度同步。

论文报告 checkpoint-level 的 Spearman correlation 约为：

\[
\rho=0.964.
\]

也就是说：

> **高 ID success 并不意味着 action representation 更好；模型完全可能通过 scene/action shortcut 提升 ID 表现，同时破坏 task-semantic structure。**

在同一个模型的 rollout 内，成功轨迹的 action–instruction cosine similarity 也高于失败轨迹，进一步说明这种 semantic organization 与 policy success 有相关性。

---

## 3. InfoNCE 是什么

InfoNCE 可以简单理解成：

> **把正确配对拉近，把错误配对推远。**

假设一个 batch 里有 4 条样本：

```text
A1 ↔ T1: “抓白色方块”
A2 ↔ T2: “抓蓝色方块”
A3 ↔ T3: “打开抽屉”
A4 ↔ T4: “把杯子放进碗里”
```

经过两个 projection head 后：

\[
z_a^i=T_a(h_a^i),\qquad z_t^i=T_t(e_t^i).
\]

构造相似度矩阵：

\[
S_{ij}=\frac{\mathrm{sim}(z_a^i,z_t^j)}{\tau},
\]

其中通常使用 cosine similarity，\(\tau\) 是 temperature。

理想情况：

```text
            T1   T2   T3   T4
A1          高   低   低   低
A2          低   高   低   低
A3          低   低   高   低
A4          低   低   低   高
```

对 A1 来说：

\[
\mathcal L_1
=-\log
\frac{\exp(S_{11})}
{\sum_j\exp(S_{1j})}.
\]

因此训练会同时：

1. 提高 matched action–instruction pair 的相似度；
2. 降低 batch 内其他 unmatched pair 的相似度。

论文使用双向版本，即同时做：

\[
Action\rightarrow Text
\]

和：

\[
Text\rightarrow Action.
\]

### 两个 projection head 怎么训练？

两个 head 都通过 InfoNCE 的梯度共同训练。

形式上二者都输出同一维度（例如 512D），因此可以直接计算相似度；更重要的是，它们共享同一个 contrastive objective，所以逐渐形成一个“共同的对比空间”。

但需要强调：

> **这个 shared space 不是天然存在的，也不是预先给定的 semantic manifold，而是两个 projection head 在 InfoNCE 监督下共同学出来的坐标系。**

因此，高 retrieval accuracy 最严谨的解释应该是：

> action representation 与 language representation 中存在一种可以通过小型 projection 网络抽取并对齐的共享结构。

而不是说二者原始 hidden representation 本来就在“同一个语义空间”。

---

## 4. Projection-head 对齐存在的一个重要问题

如果 action-side 和 text-side projection 都是 trainable：

```text
Action feature → T_a ┐
                     ├→ learned contrastive space
Text feature   → T_t ┘
```

那么两个 projection head 理论上可以共同发明一个 task code，而不一定严格保留外部 semantic encoder 原始空间中的几何关系。

例如：

```text
“put spoon in bowl” → [1,0,0,...]
对应 action          → [1,0,0,...]

“close cabinet”     → [0,1,0,...]
对应 action          → [0,1,0,...]
```

InfoNCE 可以做到非常好，但这个空间未必是真正具有自然语言语义结构的“semantic manifold”。

因此论文所谓的 “anchoring to semantic manifold” 更严谨的表述应该是：

> **contrastive alignment with a frozen semantic encoder。**

冻结 semantic encoder 有帮助，但因为 text projection \(T_t\) 仍然可训练，所以目标空间并非完全固定。

---

## 5. 真正方法：Shared–Private Decomposition

作者认为，单纯把整个 action feature 全部拉向 language embedding 会产生矛盾：

- 语义希望同一个任务在不同场景下保持不变（semantic invariance）；
- 控制却必须对位置、姿态、embodiment、timing 等细节敏感（action sensitivity）。

因此将每个 action-token feature \(h_i^{(k)}\) 拆成：

### Shared semantic feature

\[
z_i^s=E_s(h_i^{(k)}),
\]

希望表达：

- 当前任务是什么；
- 当前 intention 是什么；
- “pick fruit / stack dishes / close cabinet”等高层 task semantics。

### Private motor feature

\[
z_i^p=E_p(h_i^{(k)}),
\]

希望表达：

- 当前 EEF 位置；
- embodiment-specific geometry；
- timing；
- precise motion；
- 其他低层执行细节。

直观上：

```text
Shared  = What am I doing?
Private = How exactly am I doing it?
```

对于同一个 “put apple on plate” 任务，如果苹果位于不同位置，两条真实轨迹可以完全不同：

```text
Trajectory A：先向左接近
Trajectory B：先向右接近
```

理想情况下：

\[
z_s^A\approx z_s^B,
\]

但：

\[
z_p^A\neq z_p^B.
\]

---

## 6. Shared feature 如何与 instruction 对齐

Shared tokens 不直接平均，而是通过 learnable-query attention pooling：

\[
\alpha_i
=
\frac{\exp(q^\top z_i^s/\sqrt{d_s})}
{\sum_m\exp(q^\top z_m^s/\sqrt{d_s})},
\]

\[
\bar z_s=\sum_i\alpha_i z_i^s.
\]

然后将 \(\bar z_s\) 与冻结 semantic encoder 得到的 instruction embedding 做双向 InfoNCE。

流程：

```text
action tokens
    ↓
Shared encoder
    ↓
semantic action tokens
    ↓
attention pooling
    ↓
“这一整组 action tokens 想完成什么”
    ↓
projection
    ↕ InfoNCE
instruction embedding
```

论文默认使用 EgoHOD 相关 encoder 作为最终 semantic anchor，并比较了 CLIP、Qwen3、Qwen3-VL 等不同语义空间。

实验中，manipulation / egocentric-action grounded 的 encoder 比纯语言 embedding 更有效，说明适合作为 action anchor 的未必是规模最大的语言模型，而可能是更理解 manipulation dynamics 的视觉/视频 representation。

---

## 7. 如何防止 Shared / Private 随便拆

仅仅定义两个 encoder 并不能保证真的解耦，所以作者增加两个约束。

### Reconstruction loss

将 shared + private feature 解码回原 action feature：

\[
h_i^{rec}=Dec(z_i^s+z_i^p),
\]

要求：

\[
h_i^{rec}\approx h_i^{(k)}.
\]

这样两部分合起来必须保留原始信息。

### Difference / decorrelation loss

鼓励 shared 和 private 不要复制同样的信息，例如通过 cosine-orthogonality：

\[
L_{diff}
=
\left(
\frac{\langle z^s,z^p\rangle}
{\|z^s\|\|z^p\|}
\right)^2.
\]

最终训练目标近似为：

\[
L
=
L_{action}
+
\lambda_{align}L_{align}
+
\lambda_rL_{recon}
+
\lambda_dL_{diff}.
\]

所有 shared/private encoder、projection、reconstruction 模块都只在训练时使用，推理时删除，因此没有额外 inference overhead。

---

## 8. 为什么选择中间层做 alignment

论文比较不同 layer，发现 mid-layer 最合适。

直观解释：

```text
Early layer：偏底层视觉与输入特征
Mid layer：task / semantic structure 较强
Late layer：越来越偏向 action generation 和具体控制
```

因此作者在中间层 action tokens 上做 semantic regularization，而不是直接在最终 action output 上做。

## 9. 实验结论

主要结论包括：

1. 简单 contrastive semantic alignment 已经能带来明显收益；
2. Shared–Private decomposition 在此基础上继续提升，但贡献小于基础 InfoNCE alignment；
3. LIBERO、SimplerEnv 和真实机器人 OOD 测试中均有提升；
4. task composition、position shift 等需要组合泛化的场景收益尤其明显；
5. manipulation-grounded semantic encoder 通常优于纯 text embedding 作为 anchor。

因此论文最强的 empirical claim 不是“提出了一个新的 action space”，而是：

> **action-token representation 中 task-level semantic organization 的强弱，与 OOD generalization 有明显相关性；主动保持这种结构可以改善 policy 泛化。**

## 10. 关键质疑 1：同一轨迹可以对应不同语义

这是我们认为这篇论文最重要的概念问题之一。

假设两个任务：

```text
Task A：抓白色方块
Task B：抓蓝色方块
```

如果白色方块和蓝色方块恰好位于完全相同的位置，两次执行的 EEF trajectory、夹爪开合、action chunk 都可能完全相同：

\[
A_{white}=A_{blue}.
\]

但语义显然不同：

\[
L_{white}\neq L_{blue}.
\]

如果所谓 action representation 真的是：

\[
z_a=f(A),
\]

那么必然：

\[
z_a(A_{white})=z_a(A_{blue}).
\]

此时却要求它同时接近两个不同 instruction embedding，本质上存在信息论冲突。

因此：

> **单独从低层 action trajectory 本身，不可能恢复完整 task semantics。**

---

## 11. 为什么论文的方法仍然能做这种对齐？

关键在于：论文所谓的 “action representation” 并不是纯粹由 action trajectory 决定的 representation。

它取的是 VLA 内部的 **action-token hidden state**。

这个 hidden state 在产生动作前已经条件化于：

- visual observation；
- language instruction；
- 当前 policy computation / multimodal context。

所以更准确应该写成：

\[
h_{action}=f(o,l,\text{policy state}),
\]

而不是：

\[
h_{action}=f(A).
\]

因此即使最终动作完全一样：

\[
A_{white}=A_{blue},
\]

也完全可能：

\[
h_{action}^{white}\neq h_{action}^{blue},
\]

因为 instruction 和 observation 不同。

这使得 InfoNCE 数学上可以成功，但也暴露了一个更大的问题：

> 高 action–instruction retrieval accuracy 可能只是说明 **action-token hidden state 保留了 instruction information**，而不是说明“机器人动作本身获得了语义结构”。

---

## 12. 关键质疑 2：Instruction-copying confound

极端情况下，模型完全可以学成：

```text
Shared  ≈ instruction / task identity
Private ≈ actual motor information
```

这样：

- InfoNCE 很容易；
- reconstruction loss 也可以满足；
- shared/private decorrelation 也可以满足；
- 最终 action head 仍然可以正常输出动作。

但此时 Shared 并不一定是从“动作”中发现了 task intention，而可能只是把输入 instruction 沿着 action-token hidden state 保存下来。

因此这篇论文更准确证明的是：

> **让 policy decision hidden states 保留 task semantics，有助于 OOD generalization。**

而不是：

> **低层 robot action trajectory 本身存在一个可以与自然语言一一对齐的 semantic manifold。**

这两个结论差别很大。

---

## 13. 更严格应该怎么验证

### 13.1 Same action / Different semantics

人为构造：

\[
A_1\approx A_2
\]

甚至：

\[
A_1=A_2,
\]

但：

\[
L_1\neq L_2.
\]

例如白块和蓝块位于同一位置，对应完全相同抓取轨迹。

如果 hidden representation 仍只随 instruction 改变，则说明 metric 很大程度在测 language information retention。

### 13.2 Same semantics / Different trajectory

保持：

```text
“抓白色方块”
```

不变，但把方块放在不同位置，使真实 trajectory 完全不同。

理想 shared/private decomposition 应满足：

\[
z_s^1\approx z_s^2\approx z_s^3,
\]

但：

\[
z_p^1,z_p^2,z_p^3
\]

明显不同。

这才是真正验证：

```text
Shared = intention
Private = execution
```

### 13.3 Language swap / counterfactual probe

固定 observation 和 motor trajectory，只替换 instruction。

如果 semantic score 随 instruction 立即变化，即使动作不变，则说明 alignment metric 主要对 language pathway 敏感。

### 13.4 分别 probe Shared / Private

建议分别测试：

- Shared → task classification；
- Shared → low-level action regression；
- Private → task classification；
- Private → action regression。

如果真的 disentangle，应看到：

```text
Shared：task 强、motor 弱
Private：task 弱、motor 强
```

论文目前还没有足够严格地证明这一点。

## 14. 更自然的 action semantics：从 Effect 入手

我们认为，robot action 与自然语言之间并不天然存在一一映射。

更合理的层级可能是：

\[
\boxed{
Action
\rightarrow
Effect / State Transition
\rightarrow
Task Semantics
}
\]

而不是直接：

\[
Action\leftrightarrow Instruction.
\]

例如：

```text
Current：白色方块在桌面
Action：向前 + close + up
Future：白色方块被抓起
```

语义 “white block is grasped” 来自 **action 对世界造成的结果**，而不仅是 low-level trajectory。

同样一条运动轨迹用于抓白块和抓蓝块时，future state / object identity 不同，因此 effect semantics 自然不同。

这对 WAM 尤其有启发：

```text
低维 action
    ↓
pixel-aligned motion / geometry representation
    ↓
future state change
    ↓
task-level semantics
```

即通过真实 world transition 作为 action 与 language 之间的桥梁，比直接将 action-token hidden state 和 instruction embedding 做 InfoNCE 更自然。

---

## 15. 与 Anchor-Align（2607.13429）的区别

两篇都认为 robot finetuning 会破坏 pretrained semantic structure，但作用对象不同。

| | Anchor-Align | Semantic Anchoring |
|---|---|---|
| 主要对象 | VLM vision-language hidden state | action-token hidden representation |
| anchor target | 原 pretrained VLM | 外部 semantic encoder |
| 对齐方式 | layer-wise MSE + coarse direction language | contrastive InfoNCE |
| action semantics | 6 个粗粒度平移方向 | task-level instruction / intention |
| decomposition | 无 | shared / private |
| 核心目标 | 防 catastrophic forgetting + language/action一致 | 塑造 action decision representation |

Semantic Anchoring 更直接针对 action representation，但也更容易受到 instruction leakage 的质疑。

---

## 16. 最终评价

这篇最有价值的 observation 是：

> **action-token representation 的 task-semantic organization 与 OOD generalization 高度相关。**

它提醒我们，评价 robot policy representation 不能只看 action MSE 或 ID success，还应该问：

- representation 是否保留 task intention；
- 同一任务的不同执行是否具有共享结构；
- 不同任务是否能被正确区分；
- semantic structure 是否真的进入最终 action decision。

方法层面，最主要的性能收益来自较简单的 mid-layer action–instruction contrastive alignment；Shared–Private decomposition 是合理补充，但论文还没有严格证明它真的实现了 intention / motor disentanglement。

因此最准确的定位是：

> **这是一篇 action-decision representation regularization 工作。它证明“让 action-token hidden state 保留 task-level semantics”有助于 OOD，但不能据此直接声称 robot action trajectory 本身存在与自然语言一一对应的 semantic manifold。**

我们认为后续更有价值的方向是，将 action semantics 建立在 **state transition / world effect** 上，而不是直接把 instruction embedding 当作 action 的唯一 semantic target。
