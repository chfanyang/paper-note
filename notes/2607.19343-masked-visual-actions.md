# Masked Visual Actions for Unified World Modeling

- ArXiv: https://arxiv.org/pdf/2607.19343
- 关键词：world model、video diffusion、visual action representation、forward/inverse modeling

## 核心问题

传统 action-conditioned video/world model 往往把 joint、EEF pose 或 action token 直接输入视频 backbone，但 action 与 RGB/video latent 的模态差异很大。

本文将 action 表示成实体在视频中的时空视觉轨迹：

```math
C=M\odot V
```

模型输入初始帧 `I_0` 和 masked visual action `C`，预测完整未来视频：

```math
p_\theta(V\mid I_0,C)
```

## 图 2：四种 action 表示

### Raw joint angles

- 控制上精确；
- 与视频模态差异最大；
- embodiment-specific；
- 模型还要学习 joint → robot geometry → contact → object response。

### Visualized end-effector pose

只显示末端位置和朝向，缺少：

- 机械臂其余连杆；
- 几何体积；
- 遮挡关系；
- 完整接触区域。

### Visualized skeleton

比单点信息更多，但仍是稀疏线框，缺少真实表面、厚度和占据区域。

### Masked Visual Actions

直接给出机器人完整视觉轨迹，使模型主要学习：

```text
已知机器人这样运动
        ↓
物体和环境如何响应
```

核心思想：

> action 条件越接近视频模型原生的像素/latent 空间，模型需要额外学习的跨模态映射越少。

## 图 3：统一 forward / inverse modeling

### Forward modeling

给定机器人轨迹：

```math
p(\text{object motion}\mid\text{robot motion},I_0)
```

流程：

```text
Policy 候选动作
→ URDF / FK / 相机渲染
→ Masked Visual Action
→ 视频模型预测完整未来
→ judge 选择最好结果
```

可用于：

- model-based planning；
- policy evaluation。

### Inverse modeling

给定目标物体轨迹：

```math
p(\text{robot motion}\mid\text{object motion},I_0)
```

流程：

```text
目标物体轨迹
→ 视频模型补全机器人操作视频
→ inverse dynamics model
→ 可执行机器人 action
```

关键观点：

> forward 和 inverse 可以被看作同一个联合视频分布在不同条件下的 completion。

## 图 4：训练数据构造

### Segmentation-based

```text
真实机器人视频
→ SAM 分割机器人
→ 保留机器人区域，其余设灰
→ Masked Visual Action
```

优点：真实、无需 URDF 与标定。  
缺点：推理时未来视频尚不存在，难以人为指定任意机器人轨迹；还可能通过遮挡轮廓泄露未来信息。

### Rendering-based

```text
关节状态
+ URDF
+ 相机内外参
→ FK
→ 机器人 mesh 渲染
→ Masked Visual Action
```

这个渲染不是额外训练的模型，而是传统图形学流程：

1. 根据关节状态做 forward kinematics；
2. 得到每个 link 的 3D pose；
3. 用相机内外参投影；
4. 用 renderer 光栅化机器人；
5. 半透明机器人、红色夹爪只是视觉设计。

渲染器不负责物理仿真，也不预测物体结果。

## 讨论与评价

真正的新意不是“mask 控制视频”，而是：

> 把 action representation 搬到视频模型熟悉的视觉空间。

局限：

- 仍依赖 URDF、标定或 segmentation；
- 是生成式相关性模型，不保证 causal physics；
- 可能出现 ghost contact 和乐观偏差。

## 研究启发

可以继续研究比完整 robot rendering 更轻、更通用，同时保留几何和时序结构的视觉 action representation，例如 ray / raxel / motion field 等。
