# When Vision Overrides Language: Evaluating and Mitigating Counterfactual Failures in VLAs

- arXiv: 2602.17659
- Main method: CAG (Counterfactual Action Guidance)
- Main benchmark: LIBERO-CF

## 1. Core question

This paper studies a failure mode that standard VLA benchmarks often hide:

> A VLA may achieve high task success while relying mostly on scene-action correlations, rather than truly letting language determine the action.

The key phenomenon is **counterfactual failure**: keep the same visual scene, but change the instruction to another valid task. The policy often ignores the new instruction and falls back to the behavior that was most common for that scene during training.

A useful conceptual form is:

```text
Ideal VLA:
P(a | o, l) depends strongly on both vision o and language l

Observed shortcut:
P(a | o, l) ≈ P(a | o)
```

The problem is therefore not simply “the model does not understand language”, but rather:

> the visual prior is so strong that language fails to control the final action.

---

## 2. Evidence that vision dominates language

The authors first test fine-tuned VLAs on LIBERO with different modalities removed.

For models such as OpenVLA-OFT, π0, and π0.5, removing language still leaves surprisingly high task success on many standard LIBERO tasks. For example, π0.5 can still solve a large fraction of tasks with vision only.

This alone does **not** prove language is being ignored, because LIBERO itself has strong scene-task correlations: in many scenes, there is effectively one dominant task, so a vision-only shortcut can work.

The stronger evidence comes from counterfactual evaluation.

---

## 3. LIBERO-CF: counterfactual benchmark

The paper constructs **LIBERO-CF** by keeping the scene largely unchanged while assigning a new, still-valid instruction.

Example:

```text
Training behavior in a scene:
Pick up the black bowl

Counterfactual test:
Pick up the cookie box
```

The benchmark contains four subsets:

- CF-Spatial: objects that were originally background elements become task targets.
- CF-Object: target object changes.
- CF-Long: new long-horizon task compositions.
- CF-OOD: tasks involving objects not seen during fine-tuning.

The important difference from paraphrase-style language OOD is:

```text
Language OOD:
same task, different wording

Counterfactual OOD:
same scene, actually different task
```

This is a much more direct test of whether language really controls the policy.

---

## 4. Grounding vs task success

The paper argues that binary task success is not enough for studying language grounding.

For example, a policy may correctly move toward and grasp the language-specified object, but fail later during placement. Task success would still be 0, even though language grounding was correct.

Therefore the paper additionally records:

- **Faithful Grounding**: the gripper contacts the object specified by the new instruction.
- **Faithful Success**: the new counterfactual task is completed.
- **Biased Grounding**: the policy instead interacts with the original training-task object.
- **Biased Success**: the policy falls back to the old task associated with the scene.

This distinction is important because many failures are not generic manipulation failures. The model is often competent, but competent at the **wrong task**.

---

## 5. Main failure pattern

On LIBERO-CF, models that look very strong on standard LIBERO collapse sharply.

A typical pattern for π0.5 is:

```text
standard LIBERO success: very high
counterfactual faithful success: very low
biased success: much higher
```

In other words:

> when the instruction changes, the model often does not become uncertain or stop; it confidently performs the old scene-specific behavior.

This strongly suggests shortcut learning rather than simple lack of motor competence.

---

## 6. Focused counterfactual intervention

The paper performs a particularly useful intervention: remove the object associated with the original training task while keeping the counterfactual target object.

Example:

```text
Counterfactual instruction:
Pick up cookie box

Original training-task attractor:
black bowl

Intervention:
remove black bowl from the scene
```

When the original task object disappears, faithful grounding and task success improve substantially.

This supports the idea that the original task object acts as a **visual attractor** that can overpower the language instruction.

This experiment is more convincing than simply showing that vision-only performance is high.

---

## 7. CAG: Counterfactual Action Guidance

The mitigation method is conceptually very simple: adapt classifier-free guidance (CFG) to robot action prediction.

Define:

- conditional policy: `π_cond = π(a | o, l)`
- unconditional / vision-only policy: `π_uncond = π(a | o)`

Then compute:

```text
π_CAG = π_uncond + ω (π_cond - π_uncond)
```

The difference

```text
π_cond - π_uncond
```

is interpreted as the action change induced by language.

CAG amplifies that language-induced change by a guidance scale `ω > 1`.

Intuitively:

```text
vision-only prior:
"in this scene I usually move toward the tape"

vision + language:
"the instruction nudges me toward the mustard"

CAG:
amplify that language-induced shift
```

The goal is not to remove visual knowledge, but to stop the visual prior from overwhelming language.

---

## 8. Bayesian interpretation

The paper motivates CAG through:

```text
P(a | o, l) ∝ P(a | o) P(l | a, o)
```

where:

- `P(a | o)` is the vision-only action prior;
- `P(l | a, o)` is language-action compatibility.

Counterfactual failure is interpreted as the visual prior being too strong relative to the language factor.

CAG conceptually sharpens the language contribution:

```text
P_CAG(a | o, l) ∝ P(a | o) P(l | a, o)^ω
```

This gives an intuitive explanation for why increasing `ω` can help language grounding.

However, the implementation is more heuristic than this probabilistic derivation suggests, because the method often performs a linear combination directly in action/output space.

---

## 9. Two CAG variants

### 9.1 Training-Free CAG

Run the same trained VLA twice:

```text
Vision + Language
        ↓
       VLA
        ↓
a_cond

Vision + empty language
        ↓
       same VLA
        ↓
a_uncond
```

Then apply:

```text
a_CAG = a_uncond + ω (a_cond - a_uncond)
```

Advantages:

- no additional training;
- can be attached to an existing VLA at test time.

Weakness:

- the original VLA was not necessarily trained to interpret an empty language input as a proper unconditional branch;
- therefore `a_uncond` may suffer from distribution shift and may not be a clean estimate of `P(a | o)`.

---

### 9.2 VA-CAG

To obtain a cleaner vision-only prior, the authors separately train a **Vision-Action (VA) model**:

```text
image
+
action supervision
↓
vision-only policy π_VA(a | o)
```

At inference:

```text
VLA(o, l) → a_cond
VA(o)     → a_uncond

CAG(a_cond, a_uncond)
```

This version generally works better because the unconditional branch is explicitly trained for vision-only action prediction.

Trade-off:

- requires extra training;
- requires running two policies at inference;
- no longer fully training-free.

---

## 10. Guidance scale

The paper varies `ω` similarly to CFG.

When `ω = 1`, CAG reduces to the original conditional policy.

Increasing `ω` generally:

- increases faithful grounding;
- decreases biased behavior;
- but overly large `ω` can reduce manipulation success.

The reason is intuitive:

```text
ω too small:
visual prior still dominates

moderate ω:
language effect is strengthened

ω too large:
action is extrapolated too far away from the familiar policy distribution
```

So CAG introduces a classic guidance trade-off between conditioning strength and action validity.

---

## 11. Important negative result: random language dropout

A natural idea inspired by classifier-free guidance is to randomly drop language during VLA training so that one model learns both conditional and unconditional behavior.

The paper finds that this can make the problem worse.

Why?

The VLA is already inclined to solve tasks from visual shortcuts. Randomly deleting language teaches it even more strongly that language is optional:

```text
vision shortcut already strong
+
training-time language dropout
→
model learns that scene alone is enough
```

This is an important result because CFG-style training tricks from image diffusion do not transfer naively to VLA learning.

---

## 12. Relation to AC-VLA

This paper and AC-VLA study essentially the same family of shortcut failures, but intervene at different stages.

### AC-VLA

Training-side mitigation:

```text
full trajectories
+
subtask supervision
+
state-conditioned wrist masking
→
reduce shortcut formation during training
```

### CAG

Test-time mitigation:

```text
trained VLA
+
vision-only prior estimate
→
amplify language-induced action shift
```

So the two approaches are complementary:

```text
AC-VLA:
prevent shortcut during training

CAG:
correct shortcut during inference
```

## 13. What I think is strongest in this paper

### 13.1 The benchmark and failure analysis are more important than the mitigation

The strongest message is:

> standard benchmark success does not imply that language truly controls the action.

A policy can perform very well on standard LIBERO by exploiting scene-task correlations, yet fail badly when asked to do another valid task in the same scene.

This reveals a genuine evaluation blind spot in current VLA benchmarks.

### 13.2 The focused object-removal intervention is particularly convincing

Removing the original task object and observing a strong recovery in counterfactual execution supports the hypothesis that certain visual objects behave as shortcut attractors.

This is stronger evidence than simply showing high vision-only success.

### 13.3 CAG is useful because it is simple

The method does not need a new backbone, planner, action head, or world model. It only estimates a visual prior and amplifies the language-dependent difference.

That makes it practical as a test-time correction mechanism.

---

## 14. Main limitations / our critique

### 14.1 Action-space guidance is not strictly equivalent to CFG in probability/score space

The theoretical argument is phrased in probability space, but the implementation often looks like:

```text
a_CAG = a_uncond + ω(a_cond - a_uncond)
```

For multimodal action distributions, linear extrapolation in action space can produce an action that lies between valid modes or outside the policy's familiar support.

So:

> the method behaves like CFG intuitively, but the mathematical equivalence is not strict.

For flow-matching policies such as π0 / π0.5, a theoretically cleaner implementation would apply guidance to the predicted flow velocity at every denoising step:

```text
v_CAG = v_uncond + ω(v_cond - v_uncond)
```

and then integrate using the guided velocity.

That would be more analogous to classical diffusion CFG.

### 14.2 Training-Free unconditional branch is imperfect

Feeding empty language to a VLA that was mainly trained with language does not guarantee a well-defined vision-only policy. The resulting branch may be partly out-of-distribution.

The stronger VA-CAG results are consistent with this concern.

### 14.3 VA-CAG increases inference cost

The better version needs a separately trained vision-action model and two policy forward passes.

Thus there is a trade-off:

```text
Training-Free CAG:
cheap to adopt, weaker unconditional estimate

VA-CAG:
cleaner bias estimate, but extra model + training + inference cost
```

### 14.4 CAG cannot create missing capabilities

If the original conditional policy contains almost no useful signal for the counterfactual task, amplifying `a_cond - a_uncond` cannot magically create a new manipulation skill.

This is why models with extremely strong visual shortcuts may still remain poor after CAG.

---

## 15. Final assessment

My overall judgment is:

> **This is a paper where the problem definition and evaluation protocol are more important than the mitigation algorithm itself.**

The most important finding is not that action guidance improves performance, but that:

```text
high VLA task success
≠
strong language grounding
```

A VLA may know what an instruction means at the representation level, yet still let scene-action correlations dominate the final action.

CAG is best understood as a simple and useful test-time heuristic:

```text
estimate what vision alone wants to do
        ↓
measure how language changes the action
        ↓
amplify that language-induced difference
```

Its conceptual simplicity is a strength, but the CFG-style probabilistic interpretation should not be overstated when the actual operation is linear mixing in action/output space.

The broader lesson for VLA research is:

> **"The model understands the language" and "the language causally controls the policy output" are two different questions, and current benchmarks often test only the former indirectly.**
