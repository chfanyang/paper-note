# Patch Policy

- ArXiv: https://arxiv.org/pdf/2607.18236
- 方法名：Patch Policy
- 关键词：dense visual representation、patch tokens

## 核心问题

很多 policy 将 ViT patch 压缩为 CLS 或 global pooling，丢失局部空间信息。

Patch Policy 保留全部 patch token：

```text
image
→ frozen ViT
→ dense patches
→ Policy Transformer
→ action head
```

## Block-Causal Attention

同一帧：

- patch 双向 attention。

不同帧：

- 只能看当前和过去。

即：

```text
空间双向
时间因果
```

## Goal image

Goal image 是正式输入，不是训练标签。

流程：

```text
goal image
→ ViT
→ goal patches
→ concat observation patches
→ policy
```

告诉策略最终视觉状态。

## Goal vector

低维目标：

- 位置；
- 接触点；
- 状态参数。

复制到每个 patch 后拼接。

## Goal 来源

论文没有统一生成模块。

可能来自：

- demonstration final frame；
- 环境定义目标；
- 用户提供；
- simulator。

## Dense patch 对比

公平对比：

```text
Patch(o,g)
vs
CLS(o,g)
```

而不是有 goal 对无 goal。

主要证据：

- WebSSL Patch vs CLS / Avg Pool；
- DINOv2 Patch vs CLS；
- patch compression ablation。

## 结论

dense patch 对：

- 多物体；
- 精细对齐；
- 接触操作

更有效。

但不能推出小模型全面替代 VLA。
