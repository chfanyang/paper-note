# GTA-VLA: Guide, Think, Act

- ArXiv: https://arxiv.org/pdf/2605.13632
- 方法名：GTA-VLA
- 关键词：interactive VLA、spatial guidance、reasoning latent

## 核心问题

传统 VLA 出错后用户难以纠正：

- 目标物体选错；
- 抓取点错误；
- 路径错误。

GTA-VLA 引入 point / box / trace 视觉交互。

## Guide

用户提供：

- affordance point；
- bounding box；
- image-space trace。

这些被编码成 Qwen3-VL 坐标 token。

## Think

Qwen3-VL 生成结构化 reasoning：

### Task CoT

任务分解。

### Vision CoT

输出：

- object box；
- placement region；
- affordance point。

### Robot CoT

输出二维末端运动草图。

Action head 使用的是 reasoning token 对应的最后层 hidden states，而不是文字本身。

## Act

慢速：

```text
Qwen3-VL
→ reasoning cache
```

快速：

```text
image + wrist image + proprioception + reasoning cache
→ flow matching action head
```

## 评价

优势：

用户提示在 reasoning 前介入，可以改变 grounding，而不是动作层硬修正。

局限：

- guidance 实验接近 oracle；
- 没解决何时请求用户帮助；
- 2D guidance 缺少深度和姿态。
