# Lifting Embodied World Models for Planning and Control

- ArXiv: https://arxiv.org/pdf/2604.26182
- 方法名：Lifting Embodied World Models
- 关键词：waypoint policy、CEM、world model planning

## 核心问题

低层 world model 通常接受高维 joint action：

```math
a^{LL}\in R^{8\times48}
```

CEM 搜索空间过高。

本文增加高层 waypoint policy：

```text
2D waypoint
→ diffusion policy
→ low-level joint action
→ world model
```

## 高层 action

选择四个身体关键点：

- pelvis；
- head；
- left hand；
- right hand。

每个点是二维图像坐标：

```math
(u,v)
```

因此 action 只有 8 维。

## waypoint 如何训练得到

训练时有未来真实人体 pose：

```text
future pose
→ forward kinematics
→ 4 个关键点 3D 位置
→ 投影到当前相机
→ 2D waypoint
→ 画到当前图像
```

不是人工标注。

## 推理时 waypoint 从哪里来

### 人工指定

用户直接在当前图像上点击四个点。

### CEM 搜索

```text
candidate waypoint
→ waypoint image
→ diffusion policy
→ low-level action
→ PEVA rollout
→ predicted goal image
→ DreamSIM score
```

CEM 不搜索 384D joint action，而搜索 8D waypoint。

## Goal image

benchmark 中 goal image 来自 Nymeria 同一真实轨迹未来时刻的第一视角帧。

它是任务定义，不是模型生成。

CEM 可以看到：

- 当前图像；
- 当前 pose；
- goal image。

真实未来 pose 只用于最终评价。

## CEM

Cross Entropy Method：

1. 采样候选；
2. rollout；
3. 打分；
4. 选择 elite；
5. 更新采样分布；
6. 重复。

CEM 是优化器，不是控制框架；MPC 可以使用 CEM 作为求解器。

## 评价

提升来自：

1. 搜索空间从 384D 降到 8D；
2. diffusion policy 提供自然 motion prior。

需要区分两者贡献。
