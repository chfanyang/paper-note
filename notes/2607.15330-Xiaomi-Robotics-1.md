# Xiaomi-Robotics-1

- ArXiv: https://arxiv.org/pdf/2607.15330
- 方法名：Xiaomi-Robotics-1 / XR-1
- 关键词：VLA、UMI、data scaling、cross-embodiment、flow matching、state-transition caption

## 核心问题

这篇论文想回答：

> 机器人 VLA 能否像 LLM 一样，通过真正大规模的数据预训练，获得稳定的数据 scaling 和模型 scaling，并把这种能力迁移到真实机器人？

其整体路线是：

```text
超过 10 万小时 UMI 真实世界操作轨迹
          ↓
自动生成与 action chunk 对齐的状态变化语言标签
          ↓
大规模 action pre-training
          ↓
约 1 万小时跨机器人 post-training
          ↓
对齐真实机器人 embodiment
+ 对齐人类命令式语言
          ↓
真实机器人部署与新任务少样本适配
```

## 一句话概括

```math
\boxed{
\text{Large-scale UMI action pre-training}
+
\text{cross-embodiment robot post-training}
}
```

预训练负责学习广泛的视觉—操作先验；后训练负责把这些先验变成真实机器人可执行的策略。

---

## 模型结构

整体采用当前常见的 VLM + action expert 路线：

```text
当前视觉 observation
+
语言 instruction
        ↓
      Qwen3-VL
        ↓
视觉—语言 KV cache
        ↓
     Action DiT
        +
robot proprioception
        +
noisy action chunk
        ↓
    Flow Matching
        ↓
最终 action chunk
```

作者将整体称为 Mixture-of-Transformers（MoT）：

- VLM 与 action DiT 层数对应；
- VLM hidden size 更大；
- action DiT 更轻；
- DiT 通过 cross-attention 读取 VLM 的视觉—语言表示。

模型规模包括约 2.6B、5.1B 和 10.5B 三档。

## Action DiT

真实 action chunk 为：

```math
A_{t:t+H}
```

加入高斯噪声：

```math
\tilde A^\tau=\tau A+(1-\tau)\epsilon,
\qquad \epsilon\sim\mathcal N(0,I)
```

DiT 学习 flow velocity：

```math
v_\theta(o_t,l,s_t,\tilde A^\tau,\tau)
```

推理时从随机 action noise 出发，通过多步 Euler integration 得到 clean action chunk。

这部分与已有 flow-matching VLA 路线相近，并不是新的 action generation 范式。

---

## VLM 辅助 Action Head：Choice Policies

除了 DiT，作者还让 VLM 本身预测多条候选 action chunk。

在视觉和语言 token 后加入：

- robot-state token；
- K 组 action query tokens；
- K 组 score query tokens。

VLM 一次输出：

```math
\hat A^1,\hat A^2,\ldots,\hat A^K
```

以及对应的预测误差：

```math
\hat s_1,\hat s_2,\ldots,\hat s_K
```

训练使用 winner-takes-all：

```math
k^*=\arg\min_k\|\hat A^k-A_{GT}\|_1
```

只有最接近 ground truth 的 candidate 主要参与 action regression；score head 学习预测每个 candidate 与 ground truth 的误差。

### 这个 Action Head 的作用

最终执行仍主要依赖 flow-matching DiT。Choice Policy 更像辅助监督：

> 强迫 VLM representation 本身变得 action-aware，从而为 DiT 提供更适合控制的视觉—语言特征。

作者还禁止 DiT attend VLM 的 action query tokens，避免 DiT 直接复制 VLM 预测动作而走捷径。

---

## 预训练数据：超过 10 万小时 UMI

UMI 数据由人手持带相机和夹爪的设备采集，通常包含：

- 第一视角视频；
- UMI 末端位姿；
- gripper 开合；
- 真实场景中的操作过程。

优势：

```text
不占用真实机器人
不绑定最终部署机器人
容易在大量真实环境中采集
```

作者称其为 embodiment-free pre-training。更严格地说，它并不是完全 embodiment-free，而是：

> 不绑定最终部署机器人的 UMI embodiment 预训练。

因为 UMI 仍然有自己的夹爪形态、运动范围和操作习惯。

---

## 自动语言标注：State-Transition Caption

长 UMI 轨迹被按固定长度切成 clips，再由大 VLM 自动描述：

- 夹爪执行了什么运动；
- 场景和物体状态发生了什么变化。

例如标签更接近：

```text
夹爪抓起桌上的白色杯子，
并将杯子移动到托盘中。
```

而不是粗粒度 episode instruction：

```text
整理桌面
```

模型学习的是：

```math
\text{current scene}
+
\text{desired state transition}
\rightarrow
\text{action chunk}
```

### 为什么重要

固定长度 action chunk 只对应长任务中的局部事件。State-transition caption 与 action chunk 的时间粒度更匹配，因此比 episode-level instruction 提供更密集、明确的监督。

这一点与 WorldScape Policy 2.0 的 event-level caption 思路一致：

> 语言监督粒度应该与动作片段的时间粒度对齐。

---

## 保留视觉语言能力

如果只训练 action，Qwen3-VL 原有的视觉语言能力可能被遗忘。

因此训练同时包含：

```math
L=L_{Flow}+L_{Regression}+0.1L_{NTP}
```

其中：

- `L_Flow`：Action DiT flow-matching loss；
- `L_Regression`：VLM Choice Policy action loss；
- `L_NTP`：普通视觉语言 next-token prediction。

视觉语言数据与 UMI action 数据按约 1:9 混合。

---

## Post-Training

预训练模型会控制 UMI，但仍不能直接控制真实机器人。

作者使用约 1 万小时跨 embodiment 数据进行后训练，包括：

- 大规模自采真实机器人数据；
- 人工切分和标注的高质量 UMI；
- Bridge V2、RT-1、DROID 等开源数据。

虽然论文把后训练数据称为相对“modest”，但约 7200 小时自采真实机器人数据本身已经是极大的规模。

## Instruction Alignment

预训练语言是描述式状态变化：

```text
夹爪将鞋子从地面移动到鞋柜中
```

真实用户输入通常是命令式：

```text
把鞋子放进鞋柜
```

Post-training 将模型从：

```math
\text{state-transition-conditioned action generation}
```

对齐为：

```math
\text{imperative-instruction-conditioned policy}
```

---

## Cross-Embodiment Action Alignment

对于机械臂，作者采用相对 EEF action，并统一不同机器人和 UMI 的末端坐标系方向，使相似运动具有相近数值语义。

例如统一：

- 沿夹爪前方移动；
- 沿夹爪左方移动；
- 绕夹爪自身轴旋转。

这比简单 padding 到同一 tensor shape 更有意义，因为它进行了：

```math
\text{geometric semantic alignment}
```

而不只是：

```math
\text{action dimension alignment}
```

不同机器人不存在的 action components 仍通过 mask 处理。

局限是，它仍未统一：

- 可达空间；
- 动力学；
- 控制频率；
- 末端几何；
- 底盘和躯干控制。

## Scaling 实验

### Data Scaling

作者在约 2 万小时 UMI 数据范围内，比较不同数据比例训练的 5B 模型。

结果显示：

- 数据越多，held-out action MSE 越低；
- 小数据设置更早 overfit；
- 大数据设置后期仍持续优化。

重要限定：

> 虽然总数据声称超过 10 万小时，但严格受控的 data-scaling experiment 主要只覆盖约 2 万小时，而不是完整 10 万小时。

因此论文证明的是一个积极的 empirical scaling trend，而不是完整的 100K-hour scaling law。

### Model Scaling

在相同数据上比较约 2.6B、5.1B、10.5B 模型：

- 模型越大，action prediction error 越低；
- 但数据规模的影响大于模型规模。

论文据此认为，目前机器人策略的首要瓶颈仍然更偏向数据覆盖，而不是模型容量。

---

## Scaling 是否迁移到真实机器人

所有模型采用相同 post-training recipe，只改变预训练阶段使用的 UMI 数据量。

随着 action pre-training 数据增加，未见环境和未见实例上的真实机器人成功率显著提升。

需要注意，这里是：

- 任务类别在后训练中见过；
- 环境和物体实例未见过。

因此更准确地说是：

> unseen environment / unseen instance generalization

而不是完全 unseen task zero-shot。

---

## 新任务少量数据适配

论文还展示，在 phone packing、printer refilling、laundry loading、box packing 等新任务上，大规模 UMI 预训练可以降低后续 fine-tuning 所需的数据量。

但性能增益同时可能来自：

- 更多预训练数据；
- 自采数据与部署机器人更接近；
- action coordinate alignment；
- post-training recipe；
- 模型结构。

因此不能把全部提升只归因于“10 万小时”这一变量。

# 我们的最终看法

## 1. 架构创新有限，真正贡献在数据与训练配方

我们认为这篇最重要的贡献不是 MoT、Flow Matching 或 Choice Policy。

这些模块本质上仍属于当前常见的：

```text
Qwen3-VL
+
flow-matching Action DiT
+
辅助 action supervision
```

架构本身没有形成新的 VLA 范式。

真正有价值的是：

1. 将 UMI 操作数据扩展到 10 万小时级；
2. 用 state-transition caption 使语言与 action chunk 时间粒度对齐；
3. 用大规模真实机器人 post-training 完成 embodiment alignment；
4. 观察到数据量和模型规模增加带来的经验 scaling trend；
5. 证明 UMI action pre-training 对真实机器人部署和少样本适配具有迁移价值。

因此更准确的定位是：

> **一篇机器人 action foundation model 的数据 scaling 技术报告，而不是一篇架构创新论文。**

## 2. “10 万小时”不能被理解成 10 万小时机器人数据

绝大部分预训练数据是 UMI，而不是机器人真实执行。

UMI 能够提供：

- 广泛的真实环境覆盖；
- 人类操作中的抓取与移动策略；
- 大量视觉—动作对应关系；
- 丰富的物体状态变化。

但 UMI 不能完整提供：

- 真实机器人可达性；
- 控制延迟；
- 机器人碰撞；
- 真实接触力；
- 不同机器人动力学；
- 真实机器人失败与恢复分布。

所以约 1 万小时 cross-embodiment post-training，尤其数千小时真实机器人数据，并不是次要步骤，而是整个方案能落地的关键。

我们更愿意把训练流程理解为：

```text
10 万小时 UMI
→ 学习广泛视觉—操作先验

约 1 万小时机器人 / 对齐数据
→ 将先验转成真实可执行 policy
```

## 3. Scaling 证据积极，但不能称为成熟 scaling law

论文观察到单调 scaling 趋势，这一点值得肯定。

但距离 LLM 风格的成熟 scaling law 仍有明显差距：

- 受控 data scaling 主要只覆盖约 2 万小时；
- 数据点和模型尺寸仍较少；
- 主要预训练指标是 action MSE；
- 没有 compute-optimal 分析；
- 没有充分分离数据小时数、数据多样性和标注质量；
- 后训练数据本身规模也很大。

因此更准确的结论是：

> **论文观察到了可信的 empirical scaling trend，但尚未建立机器人领域完整、可预测的 scaling law。**

## 4. 最值得关注的是 action alignment，而不是统一 shape

作者统一 EEF 坐标系方向，使不同机器人和 UMI 中的相似运动具有一致几何语义。

这说明 cross-embodiment action representation 的关键不是简单的：

```text
padding + mask
```

而是：

```text
明确统一动作参考坐标系与几何意义
```

这与我们关注的 action representation 问题直接相关。

## 5. State-transition caption 可以被看成高层 action representation

State-transition language 描述：

> 一段低层动作让场景从什么状态变成了什么状态。

因此它位于低层 action 与 scene evolution 之间：

```text
低层 action trajectory
        ↕
state-transition description
        ↕
场景视觉变化
```

这是这篇对我们研究最有启发的部分之一。

一个自然方向是把：

- state-transition language；
- dense visual motion field；
- ray / raxel geometry；
- low-level robot action；

组织成层级化、几何一致的 action representation。

---

## 最终一句话评价

> Xiaomi-Robotics-1 的核心价值不在于提出新的 VLA 架构，而在于展示了一条“超大规模 UMI 操作预训练 + 大规模真实机器人对齐后训练”的可扩展路线；它提供了积极的数据 scaling 证据，但其成功依然强依赖大量真实机器人 post-training，当前结果更适合被理解为大型数据工程与训练 recipe 的成功，而不是机器人 scaling law 已经被彻底解决。
