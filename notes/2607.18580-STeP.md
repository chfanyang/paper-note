# STeP: Signal Temporal Logic for Precise Specifications

- ArXiv: https://arxiv.org/pdf/2607.18580
- 方法名：STeP
- 关键词：STL、MPC、formal specification

## 核心问题

VLM 可以理解任务，但难以可靠执行：

- 时间约束；
- 空间约束；
- 安全约束。

STeP 在 VLM 和 controller 之间加入 STL layer。

## 流程

```text
language
→ GPT-4o task decomposition
→ STL compiler
→ STL formula
→ MPC / learned policy
→ robustness monitor
→ replanning
```

## STL robustness

```math
rho(z,phi)
```

- rho > 0：满足；
- rho < 0：违反。

## MPC

MPC：

```text
当前状态
→ 预测未来 H 步
→ 优化动作序列
→ 执行第一步
→ 重新规划
```

STeP 将 STL robustness 加入 MPC objective。

## Hybrid controller

- learned policy：复杂接触任务；
- MPC：精确几何和安全约束。

STL 负责监控和切换。

## 评价

优势：

- 可解释；
- 能表达时间窗和安全约束。

局限：

- predicate library 需要人工设计；
- learned policy 只是被 monitor，并未被 STL 直接指导生成。
