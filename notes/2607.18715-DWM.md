# DWM: Separating World Effects from Actions in Latent World Models

- ArXiv: https://arxiv.org/pdf/2607.18715
- 方法名：DWM
- 关键词：latent world model、world effect、action effect、action invariance

## 核心问题

传统 latent world model 直接学习：

```math
(z_t,a_t)\rightarrow z_{t+1}
```

但下一状态的变化可能同时来自：

- 机器人 action；
- 重力、惯性、漂移等 world effect。

DWM 希望在 latent 中分解：

```math
\hat z=\hat z^w+\hat z^a
```

其中：

- `z^w`：与当前 action 无关的 world component；
- `z^a=z-z^w`：action residual。

## 方法结构

原始 LeWM：

```text
observation
→ encoder
→ latent history + action
→ predictor
→ pred head
→ 完整下一 latent
```

DWM 在共享 representation 上增加一个训练期 world head：

```text
shared representation r_t
├─ pred head  → 完整预测 z
└─ world head → world component z^w

z^a = z - z^w
```

推理时 world head 被移除，仍然只用原始 pred head rollout，因此不增加 planning 成本。

## World Consistency Loss

对同一个状态历史，替换当前 action：

```math
\hat z^w(s,a_1)\approx\hat z^w(s,a_2)
```

作者在 batch 内打乱 action，并用 InfoNCE 约束：

- 同一状态、不同 action：正样本；
- 不同状态：负样本。

这样既要求 world head 对 action 不敏感，又避免输出常数。

## Orthogonal Loss

```math
\mathcal L_{orth}=|\cos(\hat z^w,\hat z^a)|
```

希望 world component 和 action residual 少重复编码。

最终损失：

```math
\mathcal L=\mathcal L_{WM}+\lambda_{wc}\mathcal L_{wc}+\lambda_{orth}\mathcal L_{orth}
```

## 实验结论

在具有持续 world effect 的 PushT-W、Reacher-W、TwoRoom-W 等任务中，DWM 的 prediction 与 CEM planning 优于原始 LeWM；在普通任务中没有明显退化。

## 我们的核心质疑：`z^w` 到底是什么

论文证明的是：

```math
z^w(s,a_1)\approx z^w(s,a_2)
```

即 `z^w` 对当前 action 不敏感。

但这并不能充分证明：

```math
z^w \approx \phi(o_{t+1}^{a=0})
```

也就是“同一状态下执行 zero action 得到的真实下一状态”。

Action-invariant representation 还可能编码：

- 当前状态本身；
- 场景身份；
- 物体位置；
- 与 action 无关但不属于 dynamics 的视觉信息；
- 任意随 state 变化的函数。

因此：

```text
action-invariant
≠
真实 zero-action counterfactual
```

正交损失也只是 latent 几何约束，并不能自动赋予物理语义。

## 应补充的验证

在 simulator 中从同一状态分别执行真实 action 与 zero action：

```math
z_{t+1}^{0}=\phi(o_{t+1}^{a=0})
```

直接检验：

```math
\hat z^w\stackrel{?}{\approx}z_{t+1}^{0}
```

以及：

```math
\hat z^a\stackrel{?}{\approx}\phi(o_{t+1}^{a})-\phi(o_{t+1}^{0})
```

还可以训练 linear probe，将 `z^w` 解码为：

- 物体位置与速度；
- 重力方向位移；
- 机器人状态；
- zero-action rollout。

## 评价

较可靠的结论：

> action-invariant auxiliary head 和 orthogonal residual regularization 能改善带外部动力环境中的 latent prediction 与 planning。

证据不足的强结论：

> 模型已经识别并分离了真实的 world effect 与 action effect。

更准确的定位是：

> 一种有效的 representation regularization 方法，而非已被充分验证的物理因果分解。
