# WorldScape Policy 2.0

- ArXiv: https://arxiv.org/pdf/2607.18840
- 方法名：WorldScape Policy 2.0
- 关键词：world action model、long-horizon planning、memory、latent subgoal

## 核心问题

现有 WAM 往往只看当前帧或短历史，难以判断长任务已经完成了哪些阶段。本文在 joint video-action causal DiT 上加入：

- 短期视觉记忆；
- 长期事件语义记忆；
- VLM latent planning；
- semantic forcing。

## 基础模型

```text
future video latent
+
future action tokens
→ shared causal DiT
→ future video + action chunk
```

不同 embodiment 共享 backbone，但使用各自的 action encoder / decoder。

## 一次自主规划推理的完整流程

### 1. 输入 Qwen3-VL

当前时刻输入：

- 当前 head-view；
- 高层任务指令；
- 固定 planning prompt。

Qwen3-VL 首先做 prefill，并从最后一层取 perception tokens：

```math
u_t=H^L_{VLM}(o_t^{head},y)
```

它表示“当前看到了什么”。

### 2. 生成 planning tokens

Qwen3-VL 在同一 KV cache 上继续生成若干 planning token。真正送给后续模块的是生成这些 token 时最后一层的 hidden states：

```math
r_t^{1:K}
```

它们表示“下一步应该做什么”。

拼接：

```math
q_t=[u_t;r_t^{1:K}]
```

`q_t` 是 current reasoning latent。

### 3. 历史中存什么

过去每个 action chunk 都保存一个：

```math
q_j=[u_j;r_j^{1:K}]
```

因此长期记忆存的是过去 Qwen3-VL 最后一层的 perception / planning hidden states，不是原始 RGB，也不是原始 action。

## 历史压缩与四类 memory

### Compact Full History

每个历史 chunk：

- perception tokens 用 attention pooling 压成 gist tokens；
- planning tokens 保留；
- 全部拼成 `H_t`。

### Global History

输入：

- 高层任务 embedding；
- `Mean(H_t)`。

输出固定数量 global slots，用于概括“整个任务做到哪一步”。

### Local Active

保留最近若干历史 chunk 的完整 `q_j`，用于表示“当前子任务最近进行到了哪里”。

### Event Boundary

对每个历史 `q_j` 求平均：

```math
\bar q_j=Mean(q_j)
```

计算相邻变化：

```math
d_j=1-\cos(\bar q_j,\bar q_{j-1})
```

选择变化最大的若干位置，并保留对应 chunk 的完整 token，作为关键阶段切换点。

### 最终 memory bank

```text
Global History
+ Local Active
+ Event Boundary
+ Compact Full History
→ memory bank B_t
```

## 检索与门控

当前 `q_t` 作为 Query，历史 bank 作为 Key / Value，做 cross-attention 检索。

然后用 sigmoid gate 做 residual fusion：

```math
\hat q_t=q_t+\alpha\gamma_t\odot m_t
```

`qhat_t` 最后作为 Joint DiT 的 cross-attention condition，告诉模型“当前应该执行哪个子任务”。

## 短期视觉记忆

最近真实观测经过冻结 VAE：

```math
Z_t^{vis}=z_{t-S_v:t}^{obs}
```

它们作为 causal DiT 的 clean visual prefill，负责：

- 最近接触；
- 夹爪开合；
- 局部运动方向；
- 视觉连续性。

因此：

```text
长期事件记忆：任务做到哪一步、下一步做什么
短期视觉记忆：最近具体怎么动、是否接触
```

## Semantic Forcing

训练数据中有当前 event 的细粒度 caption `c_t`：

```text
c_t
→ frozen T5
→ subtask semantic embedding s_t
```

另一方面：

```text
高层任务 + 当前图像 + 历史
→ qhat_t
```

用余弦损失让 `qhat_t` 接近 `s_t`。推理时不再提供细粒度 caption，只靠高层任务和历史自主推断 subgoal。

## 评价

优点：

- 明确区分任务进度记忆与局部动力学记忆；
- 比直接拼接全部历史帧更有结构；
- semantic forcing 的训练逻辑清晰。

局限与质疑：

- 历史中包含 VLM 自己过去的 planning latent，错误可能累积；
- event-boundary latent change 可能只是视角或遮挡变化；
- memory 内容本身缺乏可解释性验证；
- Global / Local / Boundary 三种 view 的独立收益没有被充分拆解。
