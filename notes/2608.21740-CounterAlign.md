# CounterAlign: Counterfactual Supervision for Vision-Language-Action Models

- arXiv: 2608.21740
- 主题：VLA、Counterfactual Supervision、Reward Learning、Offline RL、Language Grounding

## 1. 核心问题

普通 Behavior Cloning（BC）只给模型正监督：

```text
Instruction + Observation -> Expert Action
```

即只告诉模型“这个动作是对的”，但不会显式告诉模型：

> 在同一个场景下，如果 instruction 改了，那么原来那条 expert action 可能就是错的。

这会导致 VLA 很容易学习：

```text
scene -> memorized action
```

而不是：

```text
(scene, instruction) -> correct action
```

CounterAlign 的核心思想就是：从已有 expert demonstrations 中人工构造 counterfactual tuples，让模型既看到“应该做什么”，也看到“在这个 instruction 下不应该做什么”。

整体流程：

```text
Expert demonstrations
        ↓
Counterfactual relabeling
        ↓
训练两个 discriminator
        ↓
得到 instruction-grounded reward
        ↓
Offline RL / IQL
        ↓
Advantage-weighted flow matching
        ↓
最终 VLA
```

推理时，discriminator、Q/V、relabeling 全部删除，只保留 VLA。

## 2. Counterfactual Relabeling

设一条原始 expert tuple 为：

\[
(o,l,a)
\]

其中：

- \(o\)：当前 observation；
- \(l\)：instruction；
- \(a\)：expert action chunk。

### 2.1 Original Sample：Positive

原始 demonstration：

```text
Instruction:
pick up the bowl from table center

Observation:
当前桌面场景

Action:
真正抓 table center 的 bowl
```

这是确定的 positive：

\[
(o,l_{center},a_{center})^+
\]

希望 relabeling discriminator 给高分。

---

### 2.2 Instruction Relabeling：Negative

保持 observation 和 action 不变，只替换 instruction：

```text
Instruction:
pick up the bowl next to the plate

Observation:
不变

Action:
仍然抓 table center 的 bowl
```

即：

\[
(o,l_{plate},a_{center})
\]

语言要求去 plate 旁边，但动作还是去 center，因此这是比较可靠的 negative。

这类样本的作用是让 reward model 明确学到：

> 一个动作本身可以很流畅、很像专家，但如果和当前 instruction 不匹配，仍然应该低分。

---

### 2.3 Action Relabeling：Negative

保持 instruction 和 observation，替换成另一条 trajectory 的 action：

\[
(o,l_i,a_j)
\]

例如 instruction 还是“抓红杯”，但换进来一条原本用于抓蓝碗的 action。

它主要用于构造“任务语义正确，但动作不合适”的负样本。

注意：action-relabeled tuple 不能直接拿去做 Bellman critic training，因为新的 next state 不知道。原始 transition 是：

\[
(o_t,a_t,o_{t+1})
\]

换成 \(a_j\) 后，并不知道真正的 \(o'_{t+1}\)。

所以 action relabeling 更适合用于 reward/discriminator 学习，而不是直接作为 transition 去训 Q。

---

### 2.4 Instruction-and-Action Relabeling：Unlabeled

同时换 instruction 和 action：

\[
(o,l_j,a_k)
\]

这类样本不能简单标成 negative。

原因是它有可能恰好还是合法的：

```text
Instruction:
pick up the bowl next to the plate

Action:
从另一条相似 trajectory 抽来的动作
```

如果这个动作在当前 observation 下刚好真的能去抓 plate 旁边的 bowl，那么它其实是 positive。

因此：

\[
\boxed{\text{Joint relabeled sample} = \text{Unlabeled}}
\]

而不是硬标成 0。

### 这类样本的意义

它不是“再造一批负样本”，而是提供：

> 物理上看起来合理，但语义上可能正确也可能错误的 ambiguous samples。

这类样本更接近真实 policy 的决策边界：

- 前半段可能正确、后半段偏掉；
- 动作大方向正确，但并不一定能完成任务；
- 一条轨迹可能同时符合多个 instruction；
- 同一 instruction 也可能对应多种合法轨迹。

因此它能让 reward model 学得比简单二分类更柔和。

## 3. nnPU：为什么需要 Positive-Unlabeled Learning

Joint relabeling 得到的是 unlabeled data：

```text
Positive:
P P P P P

Unlabeled:
? ? ? ? ? ? ?
```

Unlabeled 真实上可能是：

```text
P N N P N N P
```

但训练时不知道每条标签。

如果粗暴地把所有 U 都当 negative，会制造大量 false negative。

PU learning 假设：

\[
P_U = \pi_p P_+ + (1-\pi_p)P_-
\]

其中：

- \(P_+\)：positive distribution；
- \(P_-\)：negative distribution；
- \(P_U\)：unlabeled distribution；
- \(\pi_p\)：U 中 positive 的比例。

利用：

\[
\mathbb E_U[\ell(g,-)]
=
\pi_p\mathbb E_+[\ell(g,-)]
+
(1-\pi_p)\mathbb E_-[\ell(g,-)]
\]

可以从整体统计上估计 negative risk，而不需要给每个 U 样本逐条打标签。

### 为什么是 nnPU？

普通 PU 在有限样本、神经网络过拟合时可能得到：

\[
R_- < 0
\]

但分类风险不应该是负数。

nnPU（non-negative PU）通过：

\[
\boxed{R_-^{nnPU}=\max(0,R_-)}
\]

把负风险截断在 0，避免模型通过把 risk 推到负无穷来过拟合。

CounterAlign 的 relabeling discriminator 实际上同时使用：

\[
\mathcal L^{rel}
=
\lambda\mathcal L_{PN}
+
(1-\lambda)\mathcal L_{nnPU}
-
\alpha_H\mathcal H(D^{rel})
\]

其中：

- \(L_{PN}\)：明确 positive / negative 样本；
- \(L_{nnPU}\)：positive + unlabeled；
- entropy regularization：避免 discriminator 输出过度饱和到 0/1。

## 4. 两个 Discriminator 分别做什么

CounterAlign 有两个“外部裁判”。

### 4.1 \(D_{adv}\)：动作像不像专家

输入：

\[
(l,o,a)
\]

主要区分：

```text
Expert action
vs.
Current policy-generated action
```

它关注的是 low-level action fidelity，例如：

- 是否抖动；
- 轨迹是否偏；
- gripper 时机是否合理；
- 动作整体是否像 expert distribution。

可以理解成：

> “这动作做得像不像一个靠谱专家？”

---

### 4.2 \(D_{rel}\)：动作是不是在执行当前语言

同样输入：

\[
(l,o,a)
\]

但训练数据主要来自 counterfactual relabeling。

它判断的是：

> 在当前 observation 下，这个 action 是否符合 instruction？

例如：

```text
Instruction: 抓蓝杯
Action: 非常流畅地抓红杯
```

可能：

\[
D_{adv}\text{ 很高}
\]

但：

\[
D_{rel}\text{ 很低}
\]

所以两个 discriminator 的分工是：

```text
D_adv：做得像不像专家？
D_rel：做的是不是 instruction 要求的事？
```

---

## 5. Discriminator 和 VLA Transformer 怎么连接

它们不是直接插进 VLA Transformer 里面的某一层。

更准确是：

```text
Instruction + Observation
        ↓
    VLA Transformer
        ↓
    Action Expert
        ↓
    action chunk a
        ↓
   (l, o, a)
     /      \
    ↓        ↓
 D_adv     D_rel
    ↓        ↓
   score   score
      \      /
       ↓    ↓
       Reward
         ↓
       Q / V
         ↓
     Advantage
         ↓
加权 Flow-Matching loss
         ↓
重新更新 VLA
```

所以 discriminator 更像训练时期的外部 reward model，而不是 VLA forward path 中的组件。

推理时全部删除。

---

## 6. Reward 怎么合成

两个 discriminator 的 score 合成 instruction-grounded reward：

\[
r(l,o,a)
=
(1-w)\log D_{adv}(l,o,a)
+
w\log D_{rel}(l,o,a)
\]

因此一个动作要得到高 reward，需要同时：

1. 像 expert；
2. 符合当前 instruction。

例如：

| 动作 | \(D_{adv}\) | \(D_{rel}\) | Reward |
|---|---:|---:|---:|
| 流畅抓蓝杯，语言也是抓蓝杯 | 高 | 高 | 高 |
| 流畅抓红杯，但语言说抓蓝杯 | 高 | 低 | 低 |
| 朝蓝杯乱抖过去 | 低 | 中等 | 低 |

---

## 7. 为什么还需要 Offline RL

Discriminator 只给当前动作即时 reward：

\[
r_t
\]

但机器人任务是长时的。

例如“抓蓝杯”可能经历：

```text
t=0：靠近蓝杯

t=1：对准

t=2：闭合夹爪

t=3：抬起
```

第 0 步即时 reward 可能并不高，但它会导向后面成功。

因此需要学习动作长期价值：

\[
\boxed{Q(s_t,a_t)}
\]

其中状态：

\[
s_t=(o_t,l)
\]

Q 近似满足：

\[
Q(s_t,a_t)
\approx
r_t + \gamma V(s_{t+1})
\]

所以 Q 的含义是：

> 从当前 instruction + observation 下执行这条 action 开始，未来累计 reward 有多高？

---

## 8. IQL 怎么给 dataset action 打长期分数

CounterAlign 使用 Implicit Q-Learning（IQL）。

核心原因：offline dataset 中只覆盖很少一部分连续 action，不能像普通 Q-learning 那样随便最大化：

\[
\max_a Q(s,a)
\]

否则很容易查询到 dataset 外的 OOD action。

IQL 只在数据集中真实出现过的 action 上学 Q。

同时用 expectile regression 学：

\[
V(s)
\]

可以理解为：

> 当前状态下，dataset 里“比较好的动作”一般能有多高价值。

然后定义：

\[
A(s,a)=Q(s,a)-V(s)
\]

即 Advantage。

它表示：

> 这条动作比当前状态下的平均/较优行为好多少。

---

## 9. Advantage 怎么回到 Flow-Matching Actor

普通 flow matching 对所有 expert demonstration 一视同仁。

CounterAlign 用：

\[
\exp[\beta(Q-V)]
\]

作为每条 action 的模仿权重：

\[
\mathcal L_{actor}
=
\mathbb E
\left[
 e^{\beta(Q-V)}
 \mathcal L_{FM}
\right]
\]

因此：

```text
Q - V 大：
这条动作在当前 instruction 下长期价值高
→ 强烈模仿

Q - V 小/负：
长期价值一般或差
→ 少学
```

所以 CounterAlign 不是“拿 Q 去搜索 1000 条动作再挑最高”，而是：

\[
\boxed{
\text{在 offline dataset support 内重新排序和加权 expert actions}
}
\]

---

## 10. Counterfactual negative 最终怎么让 VLA 更听语言

整条链路是：

```text
Counterfactual negative
        ↓
训练 D_rel
        ↓
错误 instruction-action 配对得到低 reward
        ↓
Q(o,l,a) 变成 language-conditioned
        ↓
同一个 action 在不同 instruction 下价值不同
        ↓
Advantage 也变成 language-dependent
        ↓
Flow-matching actor 对不同 action 的模仿强度不同
        ↓
最终 VLA 更依赖 instruction
```

例如同一个抓红杯动作：

\[
Q(o,l_{red},a_{red})=9
\]

但：

\[
Q(o,l_{blue},a_{red})=2
\]

这就是它真正实现 language grounding 的机制。

## 11. 两个 Discriminator 在什么时候工作

### \(D_{rel}\)

主要依赖固定 counterfactual dataset：

- Original positive；
- Instruction relabel negative；
- Action relabel negative；
- Joint relabel unlabeled。

因此它比较像一个固定/阶段性更新的 semantic reward model。

### \(D_{adv}\)

需要当前 policy-generated actions：

```text
Expert action → positive
Current policy action → negative
```

因为 policy 不断变化，\(D_{adv}\) 也需要随 actor 更新而更新。

所以整体训练形成一个闭环：

```text
Policy
  ↓ 生成 action
D_adv
  ↓
Reward
  ↓
Q / V
  ↓
Advantage
  ↓
Policy 更新
  ↓
新的 policy action distribution
  ↓
继续更新 D_adv
```

## 13. 和其他近期方法的关系

### CAG

- 问题：vision prior 压过 language；
- 方法：test-time 放大 conditional - unconditional action difference；
- 定位：推理侧纠偏。

### AC-VLA

- 数据拆成 subtask；
- state-conditioned wrist masking；
- 仍是 BC-style training；
- 定位：训练数据层面减少 shortcut。

### Anchor-Align

- representation anchoring；
- coarse language-action alignment；
- 定位：防 catastrophic forgetting + representation regularization。

### Semantic Anchoring

- action-token hidden state ↔ instruction embedding；
- InfoNCE；
- 定位：action representation semantic organization。

### CounterAlign

- 显式构造 counterfactual negative / unlabeled；
- 学 instruction-grounded reward；
- 再用 offline RL 重加权 policy learning；
- 定位：reward / RL 层面的 language grounding。

## 14. 主要优点

### 1. 负样本本身质量高

不是随机动作这种 easy negative，而是：

> 动作本身完全来自 expert，但在当前 instruction 下是错的。

因此能迫使 reward model 真正看 instruction。

### 2. 把 expert demonstration 的监督密度提高

原本一条 trajectory 只有 positive 信息。

通过 relabeling，可以从同一条数据中提取：

- 应该做什么；
- 不应该做什么；
- 哪些组合存在歧义。

### 3. Joint relabel + nnPU 承认 many-to-many ambiguity

没有粗暴地把所有 relabel sample 都标负，是一个合理设计。

### 4. 训练完没有额外推理开销

最终还是普通 VLA。

---

## 15. 我们的关键质疑

### 1. Instruction ↔ Action 天然不是一一对应

同一条动作可能服务于多个 instruction；同一 instruction 也可能有多种合法轨迹。

因此 counterfactual relabeling 的标签天然存在 ambiguity。

Similarity filtering + PU learning 只能缓解，不能从根本上消除。

### 2. Reward model 可能学新的 shortcut

Synthetic relabeling 本身可能有统计规律：

- 某些 instruction 更常出现在 negative；
- 某些 scene-task pairing 更容易被重标；
- discriminator 可能学 relabeling artifact，而不是 instruction-action compatibility。

需要更严格的 controlled counterfactual evaluation。

### 3. Offline RL 仍受 dataset support 限制

IQL 主要是在已有 demonstration 支持内重新排序和加权。

它更擅长：

- selection；
- grounding；
- recombination；

而不是凭空学习 dataset 从未出现的新 motor skill。

### 4. 训练管线较重

相比加一个 auxiliary loss，这里需要：

- \(D_{adv}\)；
- \(D_{rel}\)；
- Q；
- V；
- IQL；
- advantage-weighted actor training。

所以方法价值需要和训练复杂度一起看。

---

## 16. 最终评价

CounterAlign 最有价值的点不是 IQL 或 adversarial imitation 本身，而是：

\[
\boxed{
\text{从纯 expert demonstrations 中合成 counterfactual semantic supervision}
}
\]

它把原本：

```text
“这个动作是对的”
```

扩展成：

```text
“这个动作在这个 instruction 下是对的”
+
“这个动作在另一个 instruction 下即使很像 expert，也可能是错的”
```

然后通过：

\[
\boxed{
\text{Negative / Unlabeled}
\rightarrow
D_{rel}
\rightarrow
Reward
\rightarrow
Q/V
\rightarrow
Advantage
\rightarrow
Weighted Flow Matching
}
\]

把这种语义监督真正传回 VLA policy。

更准确地说，这是一篇：

> **“利用 counterfactual relabeling 训练 instruction-grounded reward，再通过 offline RL 改善 VLA language grounding” 的数据与训练范式工作。**
