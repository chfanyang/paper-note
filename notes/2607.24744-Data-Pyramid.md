# Data Pyramid for Embodied Manipulation

- ArXiv: https://arxiv.org/pdf/2607.24744
- 方法名：Data Pyramid

## 五层数据

从高 robot alignment 到高 scalability：

1. Real Robot
2. UMI
3. Egocentric / Exocentric human video
4. Simulation
5. General data

## 各类作用

### Real Robot

提供真实 action-result pair、接触动力学和硬件噪声。

### UMI

提供机器人兼容动作 proxy，需要 retargeting。

### Human video

提供：

- affordance；
- task structure；
- interaction prior。

### Simulation

提供：

- 大规模 action/state；
- privileged labels；
- failure 数据。

### General data

提供：

- 语言；
- 视觉理解；
- 空间推理。

## 核心观点

不同数据不是简单质量排序，而是提供不同监督。

```text
General → semantic
Human video → interaction prior
Simulation → scalable dynamics
UMI → action proxy
Real robot → hardware alignment
```
