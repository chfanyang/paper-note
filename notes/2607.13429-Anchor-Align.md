# Generalizable VLA Finetuning via Representation Anchoring and Language-Action Alignment

- arXiv: 2607.13429
- Method: **Anchor-Align**
- Core question: **How can a VLA learn robot actions without destroying the pretrained VLM representations that make it generalizable, and how can we make sure language semantics actually enter action decisions?**

## 1. Motivation

The paper argues that standard robot behavior-cloning finetuning creates two distinct problems.

### 1.1 Catastrophic forgetting of pretrained VLM representations

A pretrained VLM already knows useful semantic distinctions such as:

- pink vs. green;
- left vs. right;
- plate vs. bowl;
- object identity and spatial relations;
- robustness to many visual changes.

However, standard robot finetuning only optimizes action prediction. The BC loss does not care whether these pretrained visual-language semantics are preserved.

As a result, the model can gradually replace generalizable semantic representations with scene-specific robot shortcuts:

```text
Pretrained VLM:
"pink mug" != "green mug"
"left" != "right"

        ↓ robot BC finetuning

VLA:
"this visual scene usually means grab the green mug"
"this scene usually follows this trajectory"
```

A representative real-robot example in the paper is that the training task is to pick the **green mug**, while a pink mug is also present. At test time, when the language command switches to picking the **pink mug**, a standard BC-finetuned VLA still strongly prefers the green mug. The issue is therefore not simply that the pretrained VLM never understood the word "pink"; rather, robot finetuning weakens or bypasses the semantic information that should affect control.

### 1.2 Language and action can become decoupled

Even if the language ability itself is preserved, the language head and action head are not necessarily trained to express the same decision on the same robot observation.

For example:

```text
Language head:
"move left"

Action head:
actual end-effector motion → right
```

This motivates the second problem:

> Preserving language ability is not enough; the language representation must also be aligned with the action that the policy actually executes.

The paper therefore separates two issues:

1. **representation preservation**;
2. **language-action coupling**.

Anchor-Align addresses them with two corresponding losses.

## 2. Overall method

Training uses the same robot observation, instruction and ground-truth action chunk for three objectives:

```text
Robot image + instruction + robot state + GT action
        │
        ├──────────────────────────────────────┐
        │                                      │
        ↓                                      ↓
Frozen pretrained VLM                  Trainable VLA
(anchor teacher)                        (student)
        │                                      │
layer-wise hidden states                layer-wise hidden states
        │                                      │
        └──────── Representation Anchor ────────┘
                                               │
                                               ├── Action head
                                               │      ↓
                                               │   robot action
                                               │      ↓
                                               │   action loss
                                               │
                                               └── pre-action hidden state
                                                      ↓
                                                   projection
                                                      ↓
                                               frozen LM head
                                                      ↓
                                               motion word
                                                      ↑
GT action chunk
   ↓
coarse translation label
(left/right/up/down/forward/backward)
   ↓
language-action alignment loss
```

The total objective is approximately:

\[
\mathcal L
=
\mathcal L_{action}
+
\lambda_A \mathcal L_{anchor}
+
\lambda_L \mathcal L_{align}.
\]

The paper uses:

\[
\lambda_A = 0.1,
\qquad
\lambda_L = 0.02.
\]

All extra components are training-only. Inference remains a normal VLA forward pass, so there is no extra inference-time cost.

## 3. Vision-Language Representation Anchoring

### 3.1 Basic idea

Keep a frozen copy of the original pretrained VLM as an **anchor teacher**.

The same robot image and instruction are passed through:

- the frozen pretrained VLM;
- the finetuned VLA backbone.

For Transformer layer \(u\):

\[
H_u^A
\]

is the anchor hidden representation, and

\[
H_u^S
\]

is the student VLA representation.

The model minimizes a feature-distance loss on the visual and language tokens:

\[
\mathcal L_{anchor}^{(u)}
=
\|H_u^S[m]-H_u^A[m]\|_F^2.
\]

The loss is averaged across many/all layers rather than applied only to the final layer.

So the method is not simply:

```text
keep weights close to pretrained weights
```

but more directly:

```text
keep the representations produced on the same robot observation
close to the representations of the original pretrained VLM.
```

### 3.2 Why not freeze the VLM completely?

Full freezing preserves pretrained semantics, but prevents the backbone from adapting sufficiently to robot observations and embodiment-specific features.

The desired trade-off is:

```text
Full freeze:
preserve knowledge ✓
robot adaptation   ✗

Pure BC finetuning:
robot adaptation   ✓
knowledge retention ✗

Anchoring:
allow adaptation,
but prevent excessive representational drift.
```

This is fundamentally a **plasticity vs. preservation** trade-off.

### 3.3 Evidence that catastrophic forgetting is real

The paper tracks VLM capability during robot finetuning using GQA-style visual reasoning evaluation.

Standard BC finetuning loses most of the original VLM capability after robot training, while Anchor-Align preserves a much larger fraction.

The paper also directly compares representations with CKA similarity. Standard BC causes deep-layer representations to drift strongly away from the pretrained VLM, while anchoring keeps them highly similar.

This is one of the strongest parts of the paper: the catastrophic-forgetting story is supported not only by downstream robot success but also by internal representation diagnostics.

## 4. Language-Action Alignment

### 4.1 Core idea

The paper wants the same hidden representation that drives the action policy to also be interpretable by the pretrained language head as a coarse description of the robot motion.

It converts a continuous robot action chunk into one of six language labels:

```text
left
right
forward
backward
up
down
```

### 4.2 Converting an action chunk into a motion word

Suppose the action chunk is

\[
A \in \mathbb R^{K\times 7}.
\]

The method uses only the first three translational dimensions:

\[
A_{k,1:3}.
\]

It averages translation across the chunk:

\[
\bar v
=
\frac{1}{K}
\sum_{k=1}^{K} A_{k,1:3}.
\]

Then it selects the dominant axis:

\[
j^*
=
\arg\max_j |\bar v_j|.
\]

The sign of that component determines the language label, e.g. left/right, forward/backward, or up/down depending on the robot coordinate convention.

If the total translation is too small,

\[
\|\bar v\|_2 < 0.15,
\]

the sample is excluded from the alignment objective.

### 4.3 Where is this language label supervised?

The alignment loss is not attached directly to the action decoder.

Instead, the method takes a hidden representation near the point where the VLM has already processed:

- the image;
- the instruction;

but before action prediction begins.

Call this representation

\[
h^{pre}.
\]

A small projection maps it into the pretrained language-head space:

\[
W_{proj}h^{pre}.
\]

Then the **frozen pretrained LM head** predicts the motion word:

\[
\hat y
=
W_{lm}W_{proj}h^{pre}.
\]

The loss is:

\[
\mathcal L_{align}
=
CE(\hat y,y_{motion}).
\]

### 4.4 Why freeze the LM head?

This is an important design choice.

If the language head were trainable, it could simply adapt to an arbitrary new robot representation. Then predicting "right" would not prove that the underlying hidden representation still has the original language semantics.

By freezing the pretrained LM head, the student representation must stay in a semantic space that the original VLM language decoder can still understand.

Thus:

```text
Anchor:
preserve the pretrained semantic space.

Align:
write robot-motion information into that semantic space.
```

This makes the two modules conceptually complementary.

## 5. Why ordinary vision-language co-training is not enough

A common alternative is to mix robot BC data with external VQA/image-text data.

The problem is that the two losses are applied to different observations:

```text
Robot observation A
→ action loss

Web/VQA image B
→ language loss
```

This can preserve language capability in general, but it does not explicitly require:

> On the same robot observation, the semantic representation and executed action should describe the same behavior.

Anchor-Align instead uses the same robot sample for both representation preservation and language-action coupling.

## 6. Main experimental findings

### 6.1 Main ablation

Reported results show that both components help independently, and the combination is strongest.

Approximate results reported in the paper:

| Method | LIBERO-PRO | LIBERO-Plus |
|---|---:|---:|
| Standard VLA-Adapter | 61.0 | 85.1 |
| Align only | 65.9 | 88.6 |
| Anchor only | 68.1 | 87.3 |
| Anchor + Align | **71.9** | **90.3** |

Interpretation:

- Anchoring gives a particularly strong gain on semantic/generalization-heavy settings;
- alignment adds further robustness and helps make semantic information actionable.

### 6.2 Shuffle / Scatter controls

The authors test whether the alignment improvement is merely caused by adding an extra classification regularizer.

Two controls are important.

**Shuffle:** use incorrect direction labels.

```text
true direction: left
supervision: forward
```

**Scatter:** preserve a one-to-one mapping, but replace meaningful motion words with semantically irrelevant words.

```text
left    → purple
right   → music
forward → seven
```

These controls largely fall back toward baseline performance.

This supports the interpretation that improvement depends on the semantic meaning of the motion words rather than generic auxiliary classification.

### 6.3 Direct language-action consistency diagnostic

The paper compares:

- the direction decoded by the language head;
- the direction obtained by discretizing the actual action output.

Anchor-Align increases their agreement dramatically compared with standard VLA finetuning.

The paper also reports that trajectory-level language-action agreement becomes positively correlated with task success after Anchor-Align, whereas standard finetuning shows little relationship.

This is useful evidence that the alignment loss is changing the semantics of the control representation rather than only improving benchmark success.

### 6.4 Position-swap test

A particularly revealing test swaps the positions of target objects relative to the training layout.

Standard VLA baselines largely continue toward the memorized training location, while Anchor-Align performs substantially better.

The absolute success rate is still far from solved, but the large relative improvement supports the claim that the method reduces scene-to-trajectory memorization.

### 6.5 Real robot

The method improves two different VLA/action-head architectures on xArm7 experiments, including both regression-style and flow-matching action decoders.

This suggests the benefit is not tied to a single action-generation architecture.

## 7. Relationship to CAG and AC-VLA

These papers can be placed on the same failure axis.

### CAG: test-time correction

**When Vision Overrides Language** observes that scene-conditioned action priors can dominate language intent.

Its solution is:

```text
estimate vision-only action bias
+
amplify language-induced action change
```

So CAG is primarily a **test-time correction**.

### AC-VLA: data and perceptual shortcut prevention

AC-VLA restructures training data into full trajectories plus subtask trajectories and masks wrist-view information in selected phases.

It aims to prevent object/scene shortcuts during training.

### Anchor-Align: representation and supervision prevention

Anchor-Align instead argues that robot finetuning itself can:

1. destroy pretrained semantic representations;
2. allow language and action heads to become decoupled.

Its solution is therefore a **training-time representation-level prevention mechanism**.

A useful synthesis is:

```text
AC-VLA
→ reduce shortcut learning through data restructuring / sensor routing

Anchor-Align
→ preserve pretrained semantics and couple them to action

CAG
→ correct residual visual bias at test time
```

## 8. Critical evaluation

### 8.1 Strong point: the problem decomposition is good

The paper distinguishes two things that are often conflated:

- "the VLM forgot language/vision semantics";
- "the semantics are still present but do not control action".

The combination of GQA forgetting curves, CKA analysis, action probes, semantic-control ablations and robot benchmarks gives this diagnosis a relatively strong evidence chain.

### 8.2 Representation anchoring is the more solid contribution

Anchoring directly uses the original pretrained VLM as a teacher on the **same robot observation**. This is more targeted than generic web/VQA co-training and is conceptually clean:

> preserve useful pretrained semantics while allowing bounded adaptation to robot data.

This idea is broadly applicable beyond VLA.

### 8.3 "Language-Action Alignment" is somewhat overstated

The actual alignment target only covers six coarse translational directions:

```text
left / right / forward / backward / up / down
```

It does **not** explicitly align:

- gripper open/close;
- wrist rotation;
- contact state;
- grasp/release;
- insertion;
- force;
- task phase;
- full action trajectories;
- semantic object-action relations.

A more precise description would be:

> **language-to-coarse-translational-motion alignment**.

Therefore the paper demonstrates that coarse motion semantics are useful for grounding action into language space, but it does not yet solve full language-action alignment.

### 8.4 The alignment scheme favors reaching / pick-and-place tasks

For tasks such as insertion, twisting, tool use, contact-rich manipulation or gripper-only changes, dominant translation may not capture the important action semantics.

If translation is small, the alignment sample is skipped entirely.

This limits the universality of the current alignment design.

### 8.5 Anchoring has an inherent plasticity-preservation trade-off

Robot manipulation requires new information that the pretrained VLM may not encode well:

- precise contact;
- proprioception;
- embodiment-specific geometry;
- millimeter-scale spatial relationships;
- action-induced dynamics.

If anchoring is too strong, the backbone may fail to adapt to robot-specific needs.

Thus the method does not remove the trade-off; it controls it with a weighting hyperparameter.

## 9. Connection to WAM and action representation

The same phenomenon can plausibly occur when adapting a pretrained video model into a WAM.

A pretrained video diffusion model such as Wan already contains useful priors about:

- motion;
- temporal correspondence;
- camera geometry;
- object persistence;
- appearance invariance.

Aggressive robot-specific WAM finetuning may cause representational drift and destroy part of those priors.

This suggests a possible analogue:

```text
Frozen pretrained video model
        │
        │ layer-wise representation anchor
        ↓
Robot WAM VideoDiT
```

At the same time, one could align the robot action representation with video dynamics using a pixel-aligned geometric representation such as ray/raymap/raxel-style conditioning.

Conceptually:

```text
Anchor pretrained video semantics
+
Align robot action with visual dynamics
```

This is analogous to Anchor-Align, but in the WAM setting:

- **Anchor** protects pretrained video priors;
- **Action representation alignment** reduces the modality gap between low-dimensional robot actions and dense video features.

---

## 10. Final assessment

The paper's most important contribution is not simply another auxiliary loss. Its stronger contribution is the diagnosis that VLA finetuning must solve two separate problems:

\[
\boxed{
\text{preserve generalizable pretrained representations}
}
\]

and

\[
\boxed{
\text{ensure those representations actually affect control}
}
\]

Representation anchoring is a relatively solid and broadly reusable idea. The language-action alignment component is also useful, but its current implementation should be interpreted narrowly: it aligns robot behavior to six coarse translation words rather than the full continuous action space.

The most useful takeaway is:

> **VLA finetuning should not only ask how to teach a VLM to output actions. It must also prevent robot BC from destroying the pretrained visual-language knowledge worth transferring, and it must explicitly make that knowledge participate in the final action decision.**
