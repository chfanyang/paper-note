# Gated GeoBoN: Test-Time Scaling for World Action Models via Zero-Shot Geometric Verification

- ArXiv: https://arxiv.org/pdf/2607.17454
- 方法名：Gated GeoBoN
- 关键词：world action model、test-time scaling、training-free、optical flow、geometric verification、Best-of-N

## 核心问题

World Action Model（WAM）通常会联合生成：

- 未来主视角视频；
- 未来腕部视角视频；
- 对应的 action chunk。

由于生成过程具有随机性，同一个当前观测和指令可以采样出多组候选：

```math
\tau_i=(\hat I_i^{pri},\hat I_i^{wri},a_{i,1:H})
```

最直接的 test-time scaling 是 Best-of-N：

```text
生成 N 个候选
→ 给候选打分
→ 执行分数最好的 action
```

但存在两个问题：

1. 每个控制时刻都采样 N 次，计算代价很高；
2. 如果不训练 reward/value model，如何给候选可靠打分？

本文提出 Gated GeoBoN：

> 先用便宜的 action–future consistency gate 判断当前 rollout 是否可疑；只有可疑时才额外采样多个候选，再用跨视角三维几何一致性进行 reranking。

整个方法不训练新的 verifier，也不更新 WAM 参数。

---

## 整体流程

```text
当前观测 + 指令
        ↓
WAM 生成第一个 future-video/action rollout
        ↓
Action–Future Gate
├─ 一致：直接执行当前 action
└─ 不一致：补采样到 N_max 个候选
                    ↓
                 GeoBoN
                    ↓
      选择跨视角几何误差最小的候选
                    ↓
                 执行 action
```

Gate 负责回答：

> 是否值得花更多推理算力？

GeoBoN 负责回答：

> 多个候选中应该选择哪一个？

---

# 1. Action–Future Gate

这一阶段检查：

> WAM 输出的 action，是否与它自己生成的视频中的机器人运动方向一致？

它不是任务成功验证器，只是内部自洽性检查。

## 1.1 从 action 计算末端二维运动

对于机械臂 `r`，当前末端三维位置来自 proprioception：

```math
x_{r,0}
```

把生成的 action chunk `a_{1:H}` 应用到机器人运动学模型，得到 chunk 结束时的末端位置：

```math
x_{r,H}
```

- joint action：通过 forward kinematics 得到；
- delta EEF action：累加位移得到。

将当前和未来末端位置投影到主相机图像平面：

```math
\Delta u_r=\pi_{pri}(x_{r,H})-\pi_{pri}(x_{r,0})
```

`Δu_r` 是一个二维向量，表示：

> 根据 action，末端执行器在主相机画面中应该向哪个方向移动。

## 1.2 从预测视频计算视觉运动

在：

- 当前真实主视角图像 `I_t^{pri}`；
- WAM 预测的未来主视角图像 `Ihat_i^{pri}`；

之间计算 dense optical flow：

```math
F(p)=(\Delta x_p,\Delta y_p)
```

其中 `p` 是当前图像中的像素位置，`F(p)` 表示该位置的视觉内容在未来图像中的二维位移。

## 1.3 为什么只看末端附近的光流

整张图中有大量静止背景、其他物体、阴影和生成伪影。如果直接对全图光流求平均，机械臂运动会被背景淹没。

作者根据 action 投影出的末端轨迹，在图像上构造一个 capsule-shaped mask：

```text
当前末端 ●================● 预测未来末端
          末端轨迹附近区域 M_r
```

只平均这个区域内的光流：

```math
\bar f_r=\frac{1}{|M_r|}\sum_{p\in M_r}F(p)
```

`fbar_r` 表示：

> WAM 生成的视频中，末端执行器附近的视觉内容总体朝哪个方向移动。

## 1.4 比较 action motion 与 visual motion

计算余弦相似度：

```math
c_r=\frac{\bar f_r^T\Delta u_r}{\|\bar f_r\|_2\|\Delta u_r\|_2+\epsilon}
```

直观上：

```text
Action：末端向右
视频光流：末端区域也向右
→ c 接近 1，一致

Action：末端向右
视频光流：末端区域向左
→ c 接近 -1，不一致
```

如果任一正在运动的机械臂满足：

```math
c_r<\tau_{gate}
```

则 gate 触发额外采样。

几乎不动的机械臂会通过 idle threshold 被忽略，避免极小位移导致方向不稳定。

# 2. 这里的光流是什么

光流（optical flow）是两张图像之间的二维像素运动场。

对于当前图像中的每个像素：

```math
p=(x,y)
```

光流给出：

```math
F(p)=(\Delta x,\Delta y)
```

表示当前位于 `p` 的视觉内容，在未来图像中大约移动到：

```math
p'=p+F(p)
```

例如：

```text
当前机械臂像素位置：(100, 80)
未来对应位置：(120, 75)
光流：(20, -5)
```

含义是向右移动 20 像素、向上移动 5 像素。

本文中的光流：

- 不是机器人真实执行后的运动；
- 不是关节速度；
- 不是三维速度；
- 只是当前图像与预测未来图像之间的二维视觉位移。

因此 gate 实际比较的是：

```text
action 推算出的二维末端运动
              vs.
生成视频中观察到的二维运动
```

它只能判断 action 与 imagined future 是否自洽，不能判断任务是否成功。

例如 action 和视频都一致地朝错误物体移动，gate 仍然可能通过。

# 3. GeoBoN：跨视角几何验证

如果 gate 触发，系统补采样多个 WAM rollout，然后对每个候选检查：

> 主视角未来图和腕部视角未来图，是否能解释成同一个一致的三维场景？

## 3.1 输入冻结几何模型

对候选 `i`：

```math
(\hat I_i^{pri},\hat I_i^{wri})
```

送入冻结的几何基础模型，预测：

- 相机关系；
- depth；
- 3D point map；
- 几何置信度。

## 3.2 跨视角重投影

从主视角未来图直接预测 depth：

```math
d_i^{direct}(p)
```

同时将腕部视角预测出的 3D point map 变换到主相机坐标系，并投影到主视角，得到另一张 depth：

```math
d_i^{proj}(p)
```

如果两个视角描述的是同一个合理三维未来，两张 depth 应该接近。

评分：

```math
e_{depth}(\tau_i)=\frac{1}{|\Omega_i|}\sum_{p\in\Omega_i}\left|\log\frac{d_i^{proj}(p)}{d_i^{direct}(p)}\right|
```

最终选择：

```math
i^*=\arg\min_i e_{depth}(\tau_i)
```

并执行该候选对应的 action chunk。

这里几何误差越小，表示主视角和腕部视角越可能来自同一个一致的三维场景。

# 4. 三种推理设置

## Baseline

```text
生成一个 rollout
→ 直接执行
```

## GeoBoN

```text
每个决策点固定生成 N 个 rollout
→ 对所有候选做几何评分
→ 选择误差最小的候选
```

## Gated GeoBoN

```text
先生成一个 rollout
→ Action–Future Gate

如果通过：
    直接执行

如果不通过：
    补采样多个候选
    → GeoBoN reranking
    → 执行最佳候选
```

Gated 版本试图在性能增益与计算成本之间做折中。

---

# 5. 是否真的是 training-free

是，方法不需要：

- 微调 WAM；
- 训练新的 reward model；
- 训练 value head；
- 在线环境 rollout；
- task success label。

但 training-free 不代表没有额外推理成本。

系统仍需运行：

- optical flow；
- 多次 WAM sampling；
- 冻结几何模型；
- 跨视角重投影与评分。

因此更准确地说：

```text
不更新参数：是
不增加模型和计算：否
```

# 6. 实验结论

固定预算 GeoBoN 在多个 WAM backbone 和 benchmark 上总体优于单次 rollout，但并非每个任务类别都提升。

Gated GeoBoN 只在一部分决策点触发额外采样，却能保留 always-on GeoBoN 的大部分收益。

这说明：

> 不是所有决策时刻都需要 test-time scaling，选择性分配计算更有效率。

## 候选不是越多越好

Best-of-N 并不随 `N` 单调提升。

原因之一是 false low-score selection：

> 多个候选视觉结果几乎相同，但几何 evaluator 因噪声给某个候选异常低的误差，系统错误地将它选为最佳。

随着候选数增加：

- 找到真正好候选的概率上升；
- 找到 evaluator 噪声异常值的概率也上升。

因此适中的候选预算通常比无限增大 `N` 更合理。

# 7. 论文最强的地方

## 7.1 利用了 WAM 特有的可审计性

普通 action-only policy 只能输出 action，执行前难以检查未来。

WAM 同时输出：

```math
\text{action}+\text{imagined future}
```

因此可以在执行前检查：

- action 与视频是否一致；
- 多视角未来是否几何一致。

这篇真正利用了 WAM 相比普通 VLA 的结构优势。

## 7.2 验证信号与任务类别弱绑定

方法不需要手工定义：

- 杯子是否抓起；
- 抽屉是否打开；
- 咖啡是否完成。

而是使用通用的：

- action–future consistency；
- multi-view geometric consistency。

因此更容易跨任务和跨 backbone 使用。

## 7.3 Gate 与 selector 分工合理

```text
便宜、较弱的信号
→ 决定是否追加计算

昂贵、较强的几何信号
→ 决定多个候选中选谁
```

这种层级设计比每一步都运行昂贵 verifier 更实用。

# 8. 主要局限

## 8.1 几何正确不等于任务正确

候选可能：

- 多视角几何完全一致；
- action 与视频完全一致；
- 但抓错物体或执行错误子任务。

因此几何一致性只是合理未来的必要条件之一，不是 task success 的充分条件。

## 8.2 Gate 发现不了“一致的错误”

```text
action 错了
+
视频忠实地想象了这个错误 action
```

此时两者仍然高度一致，gate 会直接放行。

## 8.3 几何 evaluator 有噪声

Best-of-N 会放大 verifier 的异常低分，候选数量过大可能导致性能下降。

## 8.4 依赖多视角 WAM 输出

完整 GeoBoN 需要至少两个相关视角，或者其他可进行几何重投影的输出。单视角 WAM 无法直接使用完整方法。

# 9. 视频预测模型是否“学的是光流”

这个说法有一定道理，但不能直接等同。

未来帧可以粗略写成：

```math
I_{t+1}\approx Warp(I_t,F_t)+R_t
```

其中：

- `F_t`：类似光流的二维运动场；
- `R_t`：无法通过简单像素搬运解释的残差，如遮挡显现、纹理生成、形变和新区域生成。

为了预测视频，模型通常必须隐式学习：

- 当前 patch 与未来 patch 的对应关系；
- 机器人和物体向哪里移动；
- 相机运动产生的视觉变化；
- dense spatiotemporal motion correspondence。

这些能力与 optical flow 很接近。

但视频模型还必须建模：

- 三维深度和几何；
- 遮挡关系；
- 物体身份；
- 接触和因果；
- 形变、阴影、反光与外观生成。

因此更准确的说法是：

> 视频预测模型必须隐式学习类似光流的时空对应与运动场，但它学习的是更完整的 scene evolution，而不只是二维光流。

还要区分两个“flow”：

```text
Optical flow：
像素在图像平面中如何移动

Flow matching velocity：
noisy latent 在生成分布空间中如何变成 clean latent
```

二者名称相同，但含义不同。

对于 WAM，更准确的表述是：

> WAM 学习 action-conditioned scene evolution，光流只是这种场景演化投影到二维图像后的一个低层表现。

# 10. 与 training-free policy repair 的关系

Gated GeoBoN 属于：

```text
training-free resampling + selection
```

它没有直接修改原 action，而是：

```text
初始 rollout 不可靠
→ 重新随机采样多个 rollout
→ 用几何一致性挑选
```

因此它更像重新抽样，而不是局部修复。

一个自然的延伸方向是：

```text
初始 action chunk
→ 定位 action–future 或跨视角不一致的时空区域
→ 只扰动对应时间步和 action dimensions
→ WAM 重生成局部未来
→ 几何 verifier 再选择
```

这样可以从 Best-of-N 随机重采样，进一步发展为：

> 围绕已有“差一点成功”的轨迹进行 training-free local repair。

这与“以最小代价把接近成功的失败轨迹修正成成功”的研究动机更接近。
