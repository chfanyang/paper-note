# RynnBrain 1.1

- ArXiv: https://arxiv.org/pdf/2607.17977
- 方法名：RynnBrain

## 两阶段体系

### RynnBrain 1.1

Embodied VLM，学习：

- point / box / trajectory；
- contact point；
- 3D grounding；
- affordance。

### RynnBrain-VLA

flow matching action generation：

```text
instruction
+ visual tokens
+ robot state
+ noisy action
→ Transformer
→ action flow
```

## Contact Point

输出：

```math
(x,y,theta)
```

比 grasp rectangle 更直接表达接触位置和方向。

## Native 3D Grounding

直接预测 camera frame 下 3D box：

- center；
- size；
- orientation。

## 81D unified action space

按语义槽位统一：

- Arm joint；
- EEF；
- Gripper；
- Hand；
- Torso；
- Head。

不同机器人用 mask 激活。

评价：

它解决的是 action container，而不是真正统一 action semantics。

## RTC

推理期 chunk continuity：

- 不训练；
- 不更新参数；
- 只修改当前 action sample。

作用：

- 减少 chunk 跳变；
- 提高闭环频率。
