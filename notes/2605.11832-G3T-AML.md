# 2605.11832 — Learning Action Manifold with Multi-view Latent Priors for Robotic Manipulation

## 核心问题

这篇论文主要针对两个问题：

1. **单目视觉的空间理解不够稳定**：即便使用较强的 3D foundation model，单张 RGB 仍然存在深度、遮挡和视角歧义；
2. **Action Flow Matching 的预测目标是否过于间接**：传统 Action DiT 预测 flow velocity，作者认为不如直接预测 clean action 更贴近真实有效动作分布。

对应提出两个模块：

- **G3T（Geometry-Guided Gated Transformer）**：VGGT + 生成式虚拟多视角 latent，用于增强几何表示；
- **AML（Action Manifold Learning）**：把 Action DiT 的输出从 velocity prediction 改成 clean-action / x0 prediction，再由 clean action 反推出 velocity 进行迭代采样。

整体上，这是一篇 **VLA 空间表示增强 + Action Flow Matching 参数化改造** 的工作。

---

## 1. 整体数据流

```text
主相机 RGB + 可选 wrist RGB + 语言 instruction
                    │
                    ├─ Qwen3-VL
                    │    ↓
                    │ semantic tokens φ_sem
                    │
                    ├─ VGGT
                    │    ↓
                    │ spatial / 3D prior tokens φ_vggt
                    │
                    └─ LongCat-Image-Edit
                         ├─ rotate camera left
                         │       ↓
                         │   左视角 latent z_l
                         │
                         └─ rotate camera right
                                 ↓
                             右视角 latent z_r

φ_vggt + z_l + z_r
        ↓
       G3T
        ↓
geometry-enhanced tokens φ_geo
        ↓
φ_sem 作为 query 与 φ_geo cross-attention
        ↓
semantic–geometry fused representation φ
        +
robot proprioception q_t
        +
noisy action chunk A_t^τ
        ↓
     Action DiT
        ↓
predict clean action Â_t
        ↓
由 Â_t 和当前 A_t^τ 换算 velocity
        ↓
Euler update，重复若干步
        ↓
最终 action chunk
```

# 2. 为什么要做虚拟多视角

作者认为单目 RGB 天然存在深度歧义。

例如图像里一个物体很小，可能是：

- 物体本身小、距离近；
- 物体正常大小、距离远。

VGGT 虽然具有较强 3D prior，但输入仍然只有单张图，因此很多不可见区域和真实几何关系只能依赖模型先验。

论文的做法不是增加真实相机，而是使用冻结的大型图像生成 / 编辑模型 LongCat-Image-Edit，从主视角“想象”左右两个新视角。

```text
主视角图像
   ├─ prompt: rotate camera to the left
   │        → 左视角 latent
   │
   └─ prompt: rotate camera to the right
            → 右视角 latent
```

这里作者主要使用生成模型内部 latent，而不是一定先解码成完整 RGB。

### 关键理解

这并不是：

```text
单目 RGB → 获得新的真实几何观测
```

而是：

```text
单目 RGB
→ 利用预训练生成模型的世界先验
→ 猜测可能的左右视角
→ 将这些先验作为额外空间特征提供给 policy
```

因此，它提供的是 **generative geometric prior**，而不是新的传感器信息。

---

# 3. G3T：Geometry-Guided Gated Transformer

G3T 融合三类信息：

- VGGT 单目空间 tokens；
- 左虚拟视角 latent；
- 右虚拟视角 latent。

## 3.1 特征对齐

先把不同来源映射到统一维度：

\[
\tilde\phi_{vggt}=W_v\phi_{vggt},
\]

\[
\tilde z_l=W_z z_l,\qquad \tilde z_r=W_z z_r.
\]

沿 token 维拼接后做 self-attention：

\[
\phi_{aligned}
=
\operatorname{MHSA}([
\tilde\phi_{vggt};\tilde z_l;\tilde z_r
])
+
[
\tilde\phi_{vggt};\tilde z_l;\tilde z_r
].
\]

目的就是让：

```text
VGGT 几何 prior
↕
左视角 latent
↕
右视角 latent
```

之间交换信息。

---

## 3.2 左右视角 gated fusion

对齐后，将特征重新拆成：

\[
\phi'_{vggt},\quad z'_l,\quad z'_r.
\]

再根据左右视角预测 gate：

\[
G=\sigma(\operatorname{MLP}([z'_l;z'_r])).
\]

融合为：

\[
z_{fused}=G\odot z'_l +(1-G)\odot z'_r.
\]

直觉上：

```text
左视角更有用 → G 更大
右视角更有用 → G 更小
```

作者希望模型在某个虚拟视角遮挡严重或生成质量较差时，偏向另一个视角。

### 一个需要注意的限制

该 gate 本身并没有显式使用：

- epipolar constraint；
- reprojection error；
- camera-pose consistency；
- correspondence；
- cycle consistency。

所以所谓 “geometry-guided” 主要来自已经融合进来的 VGGT token，而 gate 自身本质上还是一个 learned feature selector。

另外，

\[
z_{fused}=Gz_l+(1-G)z_r
\]

强制左右两个视角权重和为 1。

这意味着如果左右两个生成视角都错，模型没有一个显式的“两个都不要”选项。

更理想的形式可能是：

\[
w_l,\quad w_r,\quad w_{reject}
\]

或者保留一个 VGGT-only fallback。

---

## 3.3 与 VGGT 再次融合

最终把融合后的虚拟多视角信息与 VGGT 表示再次做 self-attention：

\[
\phi_{geo}
=
\operatorname{MHSA}([
\phi'_{vggt};z_{fused}
])
+
[
\phi'_{vggt};z_{fused}
].
\]

得到几何增强表示 \(\phi_{geo}\)。

随后让 Qwen3-VL 的语义 token 去读取几何 token：

\[
Q=W_Q\phi_{sem},\quad
K=W_K\phi_{geo},\quad
V=W_V\phi_{geo}.
\]

即：

```text
Qwen3-VL：任务是什么 / 目标是谁
                  ↓ query
G3T：目标在哪里 / 空间关系是什么
```

最终得到任务相关的语义—几何融合表示。

# 4. AML：Action Manifold Learning 到底是什么

## 最重要的理解

先把论文里的 “manifold” 这个词暂时去掉。

AML 本质上是：

\[
\boxed{
v\text{-prediction}
\rightarrow
a/x_0\text{-prediction}
}
\]

也就是：

> **仍然是 flow matching，只是 Action DiT 不直接预测 velocity，而是先预测最终 clean action。**

---

# 5. 普通 Action Flow Matching

假设真实 action 是：

\[
a^*=10.
\]

随机噪声为：

\[
\epsilon=2.
\]

训练过程中会得到一个 noisy/intermediate action，例如：

\[
a_\tau=6.
\]

普通 velocity-prediction 的问题是：

> “现在处于 6，应该往哪个方向、以多大速度移动？”

模型学习：

\[
f_\theta(c,a_\tau,\tau)\rightarrow \hat v.
\]

推理时：

```text
随机 action noise
      ↓
predict velocity
      ↓
走一步
      ↓
predict velocity
      ↓
再走一步
      ↓
...
      ↓
最终 action
```

---

# 6. AML 改成预测 clean action

AML 输入没有本质变化：

```text
视觉 / language / geometry
+
robot state
+
noisy action A_τ
+
timestep τ
```

但 Action DiT 输出改成：

\[
\hat A_t
=
V_\theta(\phi_t,A_t^\tau,q_t),
\]

其中 \(\hat A_t\) 是模型预测的 **最终 clean action chunk**。

还是刚才的例子：

```text
真实 action = 10
当前 noisy action = 6
```

普通 flow matching：

```text
输入 6
→ 预测：“应该往右走多少”
```

AML：

```text
输入 6
→ 预测：“最终正确 action 大约是 10”
```

这就是 AML 最核心的变化。

---

# 7. 为什么 AML 最后还是要算 velocity

虽然 Action DiT 输出 clean action，但采样器仍然按照 flow ODE / Euler update 运行，因此必须把 clean-action prediction 转回 velocity。

论文使用类似：

\[
\hat v
=
\frac{\hat A_t-A_t^\tau}{1-\tau}.
\]

然后：

\[
A_t^{\tau+\Delta\tau}
=
A_t^\tau+\Delta\tau\hat v.
\]

所以完整推理过程是：

```text
当前 noisy action
        ↓
      Action DiT
        ↓
预测最终 clean action
        ↓
clean action - 当前 noisy action
        ↓
换算成 velocity
        ↓
Euler 更新一次
        ↓
新的 noisy action
        ↓
再次预测 clean action
        ↓
...
```

因此 AML **没有摆脱多步 flow matching**。

它不是：

```text
noise → 一步得到最终 action
```

而是：

```text
noise
→ 猜最终 action
→ 朝它走一步
→ 再猜最终 action
→ 再走一步
→ ...
```

---

# 8. 一个最直观的导航类比

## 普通 velocity prediction

你每一步问导航：

> “我现在应该往哪个方向走？”

导航回答：

```text
东北方向走 500 米
```

即：

\[
\text{current state}\rightarrow\text{velocity}.
\]

## AML

你每一步问：

> “我的最终目的地在哪里？”

导航回答：

```text
目标坐标是 (x,y)
```

然后采样器自己算：

```text
目标位置 - 当前坐标
→ 当前该往哪里走
```

即：

\[
\text{current state}
\rightarrow
\text{destination}
\rightarrow
\text{velocity}.
\]

# 9. 作者为什么把它叫 Action Manifold Learning

作者提出 Action Manifold Hypothesis：

> 有效机器人动作不会均匀分布在整个高维 action space 中，而是集中在受任务、物理和环境约束的一小块区域。

例如 30 步、7D action chunk：

\[
A\in\mathbb R^{30\times7}=\mathbb R^{210}.
\]

理论上是 210 维空间，但真实抓取动作只占其中非常小的一部分。

作者认为：

```text
各种 noisy action
      ↓
都预测同一个真实 clean action
      ↓
clean action 本身位于有效动作分布上
```

所以直接预测 clean action，相当于更加直接地朝“有效 action manifold”学习。

---

# 10. 但严格来说，它并没有显式学习 manifold

论文没有定义：

- manifold latent coordinate；
- manifold encoder / decoder；
- intrinsic dimension；
- tangent space；
- geodesic distance；
- projection operator；
- manifold regularization；
- valid-action constraint。

因此：

\[
\boxed{
AML \neq \text{explicit manifold learning}
}
\]

更准确的技术描述应该是：

> **Clean-action / x0-parameterized flow matching**

或者：

> **Action-prediction parameterization of flow matching**

“Action Manifold”更多是作者解释为什么 clean action 比 velocity 更有语义的一种理论叙事。

---

# 11. AML 的 loss

AML 也不是简单只做：

\[
\|\hat A-A\|^2.
\]

论文会把 clean-action prediction 换算成隐式 velocity：

\[
\hat v
=
\frac{\hat A_t-A_t^\tau}{1-\tau},
\]

再与真实 flow velocity 做匹配。

因此从优化角度看，可以理解为一个带时间权重的 clean-action regression。

这进一步说明：

> AML 更像 flow matching 的重新参数化，而不是一个新的 action generative model。

---

# 12. AML 的实验说明了什么

作者在相同 VLM / Action Expert 设置下比较 velocity prediction 与 AML。

主要趋势是：

- 短 action chunk 时 AML 有小幅提升；
- action chunk 越长，AML 的优势越明显；
- 论文据此认为 clean-action prediction 对长时间 action trajectory 更稳定。

最值得注意的是，较长 action chunk 下，velocity parameterization 的性能下降更明显，而 AML 保持得更好。

### 这个结果可以支持

\[
\boxed{
a/x_0\text{-prediction 在该设置下优于 }v\text{-prediction}
}
\]

### 但不能直接支持

\[
\boxed{
模型发现了一个低维 action manifold
}
\]

因为论文没有真正测 manifold 的维度、几何结构或投影性质。

---

# 13. 实验：G3T / 多视角空间表示

普通 LIBERO 已经接近饱和，因此这篇真正值得看的主要是 LIBERO-Plus / OOD 结果。

论文中的趋势是：

- VGGT 单独加入有收益；
- 单个虚拟视角也有收益；
- 左右两个虚拟视角优于单个虚拟视角；
- VGGT + 生成式多视角进一步提升；
- 最终再加 AML 得到完整模型最佳表现。

对 camera perturbation、layout change 等空间变化尤其有效。

这说明：

> policy 确实能从更丰富的 pixel-aligned / view-conditioned spatial prior 中获益。

---

# 14. G3T 是否真的消除了单目深度歧义

不能这样说。

因为左右视角全部由同一张 RGB 生成：

\[
z_l,z_r=f(I_{main},\text{pretrained prior}).
\]

它们没有包含新的真实信息。

因此更准确地说：

> **生成模型利用大规模预训练先验，为单目图像补充了一种“可能的多视角解释”。**

而不是：

> 获得了真实的多视角几何观测。

这意味着它仍然可能 hallucinate：

- 被遮挡物体结构；
- 透明 / 反光物体；
- 新颖形状；
- 不常见场景布局。

如果生成模型想象了一个视觉上合理但几何上错误的视角，G3T 也可能被误导。

---

# 15. “latent synthesis 避免生成伪影”需要谨慎理解

论文倾向于认为：不把虚拟视角解码成 RGB，而直接使用生成 latent，可以避免纹理伪影和视觉不一致污染策略。

更准确的说法应该是：

> latent 使用方式避免了显式 RGB decoder 带来的额外重建误差，同时让 policy 不必直接消费肉眼可见的 synthetic RGB artifact。

但生成错误仍然可能已经存在于 latent 中。

跳过 VAE decoder 并不会自动消除：

- 错误深度；
- 错误遮挡关系；
- object hallucination；
- camera-view inconsistency。

---

# 16. 最大工程限制：推理成本

训练时，虚拟多视角 latent 可以预计算并缓存。

但真实机器人部署时，每个新的 observation 都需要在线运行：

- Qwen3-VL；
- VGGT；
- 6B 级生成 / 编辑模型；
- 左右两个新视角生成；
- G3T；
- Action DiT 多步去噪。

因此整个 pipeline 的在线成本很高。

这篇工作更适合：

```text
低频空间表征更新
+
较长 action chunk
```

而不是 20–30 Hz 高频闭环控制。

作者自己也将在线 virtual-view synthesis 的效率视为实际部署问题。

---

# 17. 和 ray / raxel 思路的关系

这篇论文的路线：

```text
单目 RGB
→ 大型生成模型想象左右视角
→ latent multi-view prior
→ learned fusion
→ action
```

ray / raxel 类思路更像：

```text
camera pose / robot geometry
→ 确定性 pixel-aligned geometric representation
→ video / policy backbone
```

二者共同解决的是：

> **低维几何信息与视觉 backbone 之间存在 representation gap。**

区别在于：

| | 生成式多视角 | Ray / Raxel |
|---|---|---|
| 几何来源 | pretrained generative prior | camera model + pose |
| 是否确定性 | 否 | 是 |
| 是否可能 hallucinate | 是 | 几何计算本身不会 |
| 是否包含 appearance | 强 | 可以只保留 geometry |
| 计算成本 | 高 | 相对低 |
| 几何可解释性 | 较弱 | 强 |
| 能否补全遮挡区域 | 可以猜 | 通常不会凭空补全 |

因此这篇可以支持一个研究动机：

> VLA 的确受益于更丰富、pixel-aligned 的空间条件；但用大型生成模型生成虚拟视角成本高、几何不确定且可能 hallucinate，所以仍需要更轻、更确定、更可验证的几何 action / camera representation。

# 18. 我们的最终判断

## 对 G3T

**有效，但论文对“恢复几何”的表述偏强。**

它真正做的是：

> 用大型生成模型提供多视角先验，再与 VGGT feature 做 learned fusion。

实验支持这种空间增强对 OOD camera/layout robustness 有明显价值。

但它没有真正得到新的物理观测，也没有严格做 multi-view geometry reconstruction。

因此更准确的定位是：

> **Generative multi-view prior augmentation for VLA spatial representation.**

而不是完整解决单目 3D ambiguity。

## 对 AML

**性能现象有价值，但“Action Manifold Learning”包装明显强于方法本身。**

真正变化只有：

```text
普通 flow matching：
noisy action → predict velocity

AML：
noisy action → predict clean action
             → convert to velocity
             → Euler update
```

因此核心就是：

\[
\boxed{
v\text{-prediction}\rightarrow x_0/a\text{-prediction}}
\]

它仍然：

- 使用 noisy action；
- 使用 flow matching；
- 使用多步 iterative denoising；
- 没有显式 manifold latent；
- 没有 manifold projection；
- 没有证明真实动作空间的 intrinsic dimension。

所以更合理的结论是：

> **clean-action parameterization 对长 action chunk 的生成更稳定。**

而不是：

> 已经发现或显式学习了一个低维 action manifold。

## 整篇论文

这篇真正有价值的两点是：

1. **生成式多视角 prior 能显著增强单目 VLA 的空间鲁棒性；**
2. **Action Flow Matching 的 prediction parameterization 本身也是重要设计变量，clean-action prediction 在长 chunk 下可能更稳定。**

但两部分都存在一定叙事放大：

- G3T 并没有真正恢复唯一正确的 3D；
- AML 也没有真正显式学习 manifold。

因此最准确的一句话评价是：

> **这是一篇“生成式空间先验增强 + clean-action flow-matching 参数化”的有效工程方法；实验结果值得重视，但 Geometry 和 Manifold 两个概念的包装都比实际技术实现更强。**
