# AC-VLA: Robust Out-of-Distribution Action Execution via Compositional Learning

- ArXiv: https://arxiv.org/pdf/2607.15714
- 方法名：AC-VLA
- 关键词：compositional learning、subtask supervision、OOD generalization、wrist-view masking

## 核心问题

AC-VLA 关注的不是全新物体或全新技能，而是：

```text
训练中见过：
物体 A → 目标 A
物体 B → 目标 B

测试中要求：
物体 A → 目标 B
```

也就是已经见过的 pick / place primitive，在未见过的 object-target pairing 上重新组合。

论文认为普通 VLA 容易出现两类问题：

1. **Trajectory overfitting**：记住完整语言—轨迹模板，没有真正拆成可组合子技能；
2. **Perceptual shortcut**：在 place 阶段过度依赖腕部相机中的被抓物体外观，进而调用训练中与该物体绑定的旧目标轨迹。

---

## 方法总览

AC-VLA 不修改 VLA 主体架构，而是改变训练数据与训练时视角使用方式：

```text
原始完整示范
      │
      ├── Compositional Learning
      │     LLM 拆语言
      │     Proprioception 切轨迹
      │     完整轨迹 + 子任务轨迹混合训练
      │
      └── State-Conditioned Asymmetric Masking
            pick 阶段保留 wrist view
            place 阶段 mask wrist tokens
```

推理时仍然是普通端到端 VLA，不调用 LLM，也不做显式子任务切换。

# 1. Compositional Learning

## 1.1 LLM 拆分语言指令

例如：

```text
Put the cream cheese on the plate.
```

被拆成：

```text
1. Pick up the cream cheese.
2. Place the cream cheese on the plate.
```

论文使用 Qwen-3.5-Flash 离线生成子任务文本。

## 1.2 用 proprioception 切分轨迹

每一步 action 写成：

```math
a_t=(p_t,g_t)
```

其中：

- `p_t`：6D 末端位姿；
- `g_t`：夹爪开合状态。

对长度为 `H` 的 action chunk，计算平均末端位移：

```math
D(A_t)=\frac{1}{H}\sum_{i=1}^{H-1}\|p_{t+i}-p_{t+i-1}\|_2
```

边界条件：

```math
seg(t)=[g_t\neq g_{t-1}]\lor[D(A_t)<\epsilon]
```

也就是：

- 夹爪状态变化；
- 末端平均位移很小。

这些位置被用来近似 pick / place 等语义阶段边界。

## 1.3 对齐语言子任务与轨迹片段

LLM 输出：

```math
\{\ell_1,\ldots,\ell_N\}
```

proprioception 切出：

```math
\{\xi_1,\ldots,\xi_N\}
```

按执行顺序配对：

```math
s_i=(\ell_i,\xi_i)
```

于是原本只有：

```text
完整指令 ↔ 完整轨迹
```

现在又得到：

```text
pick instruction  ↔ pick trajectory
place instruction ↔ place trajectory
```

## 1.4 为什么仍保留完整轨迹

训练数据为：

```math
\mathcal D_{mix}=\mathcal D_{full}\cup\mathcal D_{sub}
```

两类数据作用不同：

```text
完整轨迹：
保持长时动作连贯性与阶段过渡

子任务轨迹：
让 pick / place 与细粒度语言对齐，便于重组合
```

消融显示：

| 训练数据 | In-D | Spatial OOD | Goal OOD |
|---|---:|---:|---:|
| 仅完整轨迹 | 97.4 | 35.5 | 46.6 |
| 仅子任务 | 61.4 | 54.8 | 68.6 |
| 完整 + 子任务 | 96.6 | 51.6 | 67.5 |

只训练子任务虽然 OOD 提升，但完整任务执行明显下降；混合训练在保留 In-D 能力的同时改善组合泛化。

# 2. State-Conditioned Asymmetric Masking

这是论文中最值得讨论的部分。

## 2.1 原始视角依赖实验

原始 `pi_0.5` 正常输入：

- 第三视角；
- 腕部视角；
- 语言；
- proprioception。

测试时临时移除一个视角：

| 测试输入 | Spatial | Goal | Object | Long |
|---|---:|---:|---:|---:|
| 双视角 | 98.8 | 98.5 | 99.3 | 92.9 |
| 去掉第三视角 | 52.2 | 77.7 | 68.9 | 22.2 |
| 去掉腕部视角 | 1.9 | 1.5 | 2.9 | 0.1 |

这说明模型严重依赖 wrist view。

但仅凭这个实验，只能证明：

> wrist 是模型的主要控制信号。

不能直接证明：

> 模型使用了错误的纹理捷径。

因为 wrist view 本来就包含精细抓取与接触所必需的信息。

## 2.2 作者的 shortcut 解释

作者观察到，在训练中物体和目标可能稳定绑定：

```text
cream cheese → bowl
red mug      → plate
```

测试时要求：

```text
cream cheese → stove
```

模型可能通过腕部画面中的被抓物体外观，直接调用训练中与该物体绑定的完整后续轨迹：

```text
wrist 中识别出 cream cheese
→ 记忆中 cream cheese 通常去 bowl
→ 忽略新语言中的 stove
```

因此 wrist 中的物体身份，可能成为完整任务或目标位置的代理变量。

## 2.3 训练时怎么 mask

### Pick / approach 阶段

```text
第三视角：保留
腕部视角：保留
语言：保留
```

原因：抓取需要局部几何与接触细节。

### Place 阶段

```text
第三视角：保留
腕部视角：mask
语言：保留
```

技术上是在 attention 中屏蔽 wrist tokens，而不是简单用黑图替换。

作用是迫使模型根据：

```text
第三视角全局布局
+
语言中的目标位置
```

决定放置目标。

所谓 asymmetric，指的是：

```text
pick 阶段：双视角
place 阶段：主要依赖第三视角 + 语言
```

## 2.4 Masking 的独立收益

只加入 asymmetric masking：

```text
In-D：97.4 → 96.5
Spatial OOD：35.5 → 47.3
Goal OOD：46.6 → 67.0
```

说明在几乎不损失 In-D 的情况下，place 阶段降低 wrist 依赖显著改善了重组合泛化。

完整 AC-VLA：

| Raw | Sub-task | Mask | In-D | Spatial OOD | Goal OOD |
|---|---|---|---:|---:|---:|
| ✓ |  |  | 97.4 | 35.5 | 46.6 |
|  | ✓ |  | 61.4 | 54.8 | 68.6 |
| ✓ | ✓ |  | 96.6 | 51.6 | 67.5 |
| ✓ |  | ✓ | 96.5 | 47.3 | 67.0 |
| ✓ | ✓ | ✓ | 96.7 | 64.2 | 73.3 |

子任务监督与 asymmetric masking 都有独立收益，组合后最好。

# 3. 推理流程

推理时不需要：

- LLM 拆任务；
- 轨迹切分；
- wrist mask；
- 显式 hierarchical controller。

仍然是：

```text
第三视角
+ 腕部视角
+ 完整语言指令
+ robot state
→ 原始 VLA backbone
→ action chunk
```

因此 AC-VLA 更准确地是：

> 训练期的数据重构与模态依赖塑形方法。

# 4. 我们对 wrist shortcut 证据的判断

## 4.1 论文比较充分证明了什么

较可靠的结论是：

```text
原始策略在 place 阶段存在阶段不合理的 wrist 依赖；
训练时阻断该依赖，可以显著改善 object-target 重组合泛化。
```

这一点由 masking 消融支持得比较强。

## 4.2 论文没有严格证明什么

当前证据还不能完全区分：

- 物体纹理 shortcut；
- 物体身份 shortcut；
- 一般的局部视角 task-index shortcut；
- wrist 中其他几何或姿态 cue。

所以作者所说的 “wrist texture shortcut” 机制解释略强。

更严谨的表述是：

> 模型过度使用腕部视角中的被抓物体身份，作为完整任务和目标位置的代理变量。

## 4.3 更强的因果验证

### Counterfactual wrist replacement

当前任务：

```text
cream cheese → stove
```

将 wrist 图替换成另一训练物体的 wrist 图，观察模型是否改去该物体原本对应的目标。

### 只改变纹理

保持几何、姿态和运动不变，仅替换物体纹理，检查 action 是否随纹理改变。

### 只保留几何

将 wrist RGB 替换为：

- depth；
- segmentation；
- edge；
- gripper-object relative geometry。

若 OOD 恢复，才能更有力说明问题主要来自纹理身份。

### 区域级因果遮挡

分别遮掉：

- 被抓物体；
- 夹爪；
- 背景；
- 接触区域。

检查哪个区域真正导致旧目标行为。

# 5. 局限

## 轨迹切分规则较粗

```text
夹爪变化
或
低末端位移
```

不一定等于语义子任务边界。低位移还可能来自：

- 暂停；
- 抖动；
- 障碍阻挡；
- 精细插入；
- 失败。

对 pushing、旋拧、工具使用等无明显夹爪状态变化的任务，适用性有限。

## Wrist masking 不具有普适性

closed-gripper 阶段中，wrist view 在很多任务里仍然关键：

- peg insertion；
- 插头插座；
- 倒液体；
- 工具使用；
- 开门；
- 狭窄空间搬运；
- 双手协同。

因此该设计更像针对 LIBERO pick-and-place 分布的有效归纳偏置。

## OOD 仍是封闭世界重组合

论文证明的是：

```math
\text{seen primitives} + \text{unseen pairing}
```

不是：

- 新物体；
- 新技能；
- 新语言概念；
- 新动力学；
- 开放世界 zero-shot generalization。

# 6. 最终评价

我们认为 AC-VLA 是一篇：

> 问题定义清楚、消融较完整、工程上有效的 compositional data restructuring 工作。

它最可靠地证明了：

```text
粗粒度完整语言—轨迹监督
会导致组合泛化不足；

完整轨迹 + 细粒度子任务监督
比只使用其中一种更有效。
```

Asymmetric masking 也有明显效果，但更准确的机制解释应是：

> place 阶段过度依赖局部 wrist cue，会阻碍语言指定的新目标组合。

而不是已经严格证明：

> 有害信息具体就是纹理。

这篇与 WorldScape Policy 2.0、Xiaomi-Robotics-1 的共同趋势是：

> 语言监督的时间粒度应与 action chunk 或事件片段的粒度对齐。

区别在于：

- WorldScape：用细粒度 caption 教 latent planner；
- Xiaomi-Robotics-1：用 state-transition caption 做大规模预训练；
- AC-VLA：用 subtask instruction 让 policy 重组合已有 motion primitive。
